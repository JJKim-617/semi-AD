주 지표는 **공식 test split 의 macro-F1** 이다. val 은 체크포인트 선택에만 쓴다.
갱신일 2026-08-21 (2차).

## 발견

### 1. val 이 방향을 두 번 잘못 알려줬다

E3 은 val 이 +0.016 오르는 동안 test 가 **+0.101** 올랐고, E4 는 val 이 **내려갔는데**(-0.007)
test 가 +0.099 올랐다. val 만 보고 판단했다면 증강 효과를 과소평가하고 class weight 는 폐기했을 것이다.

원인은 분할 간 분포 이동이다. val 은 Training 에서 떼어냈으므로 Training 분포(none 67.6%)를 물려받는데
test 는 none 93.3% 다. val 은 일반화 성능의 추정치가 아니라 학습 분포 내 성능일 뿐이다.

### 2. 증강과 class weight 는 대체로 같은 문제를 푼다

각각 단독으로 test macro-F1 을 0.53 에서 0.63 대로 올리는데, 둘을 합쳐도 0.6545 로 +0.02 만 더해진다.
합이 아니라 겹침에 가깝다. 두 기법 모두 다수 클래스 편향 완화라는 같은 축을 건드리기 때문으로 보인다.

다만 **작동 방식은 다르다.** 클래스별로 보면 서로 다른 클래스를 살린다.
- 증강(E3)은 **Edge-Ring 0.412 -> 0.930**, Random 0.599 -> 0.844 로 회전 대칭 패턴에 강하다.
  링과 랜덤 산포는 회전시켜도 같은 클래스라 dihedral 증강이 정확히 맞는 사전지식이다.
- class weight(E4)는 **Near-full 0.863 -> 0.989**, Donut 0.336 -> 0.514 로 극소수 클래스를 살린다.
  Near-full 은 test 95장, Donut 은 146장이다.

E4b 가 최고인 것은 두 이득을 부분적으로 함께 얻기 때문이다.

### 3. class weight 는 학습을 불안정하게 만든다

E4 는 ep4 에서 val macro-F1 0.287, accuracy 0.180 으로 붕괴했다 회복했고,
E4b 는 ep4 에서 0.161/0.143 까지 떨어지고 ep11~13 에서도 크게 요동쳤다.
역빈도 가중치가 Near-full(학습셋 기준 극소수)에 큰 가중치를 주면서 gradient 분산이 커진 것으로 보인다.
증강이 소수 클래스 샘플을 다양화하면 이 진동이 더 심해진다.

체크포인트를 val macro-F1 기준으로 고르고 있어 결과적으로는 안정적인 지점이 선택되지만,
가중치 상한(clipping)이나 focal loss 로 완화할 여지가 있다.

### 4. 남은 약점

Scratch(0.391), Loc(0.486), Center(0.523) 이 여전히 낮다.
특히 **Loc 은 어떤 기법으로도 개선되지 않았고 E1(0.571)보다 오히려 떨어졌다**.
Loc 은 "국소 결함"이라 위치와 형태가 일정하지 않아 회전 증강의 이득이 없고,
support 가 1,973장으로 적지 않아 class weight 이득도 없다. 별도 접근이 필요하다.

## 문헌 대비

공식 split + 불균형 유지 조건의 공개 수치는 macro-F1 0.7 수준이 확인된다
([Defect_KAN](https://github.com/judahobi/Defect_KAN) 0.703, 단 학습 시 공식 Test 행을 배제하지 않은 누수가 있어 낙관 편향).
현재 0.6545 는 그에 근접했으나 아직 아래다.

98~99% 대 수치는 balanced 파생 벤치마크이거나 결함 8클래스 조건이라 비교 대상이 아니다.
[인코더 선택 조사](../research/encoder_selection/README.md) 참조.

## 다음

1. **E5 사전학습 비교** — `--pretrained` 로 E4b 와 동일 조건 비교. 17만 장 규모에서 전이 이득이 크지 않을 것이라는 가설 검증.
2. **Loc 개선** — 회전 증강과 class weight 모두 듣지 않는 유일한 클래스. 혼동 행렬로 어디로 잘못 가는지 확인 필요.
3. **class weight 안정화** — 가중치 상한 또는 focal loss.
4. epoch 수를 늘려 수렴 여부 확인. 현재 15 epoch 에서 loss 가 계속 내려가는 중이다.

# 2차 사이클 — 손실 함수와 사후 보정 (2026-08-21)

## focal loss 가 class weight 를 대체한다

역빈도 class weight 를 빼고 focal(gamma=2)로 바꾸자 test macro-F1 이 0.6545 에서 0.6705 로 올랐다.
가설대로다. class weight 는 클래스 전체에 고정 배율을 걸어 극소수 클래스에 106.7(none 의 648배)이
붙고 batch 의 76.6% 에 그 클래스가 없어 gradient 가 스파이크로 들어왔다. focal 의 배율은
샘플별이고 (1-p)^gamma 로 유계라 같은 문제를 덜 파괴적으로 다룬다.

**둘을 겹치면 오히려 나쁘다.** focal + alpha 는 0.5810 으로 크게 떨어졌다.
증강과 class weight 가 겹쳤던 것과 같은 이유로, 경계를 소수 클래스 쪽으로 미는 축을
두 번 조작하면 과잉 이동이 된다.

**gradient clipping 도 도움이 안 됐다**(0.5903). 불안정이 성능의 주 원인이 아니었다는 뜻이다.

## 사후 보정 — 두 번 실패하고 세 번째에 성공

| 방법 | test macro-F1 | 판정 |
|---|---:|---|
| 스칼라 logit adjustment (Menon 식 9) | 0.6712 (+0.0007) | 무의미 |
| 클래스별 오프셋, val 에서 튜닝 | 0.6554 (-0.0150) | **해로움** |
| 클래스별 오프셋, **타겟 재가중 val** | **0.6851 (+0.0146)** | **성공** |
| (참고) oracle, test 로 직접 튜닝 | 0.6974 (+0.0269) | 상한 |

**스칼라 tau 가 무의미한 이유.** 최적 tau 가 -0.05 로 0 근처였다. 표준 long-tail 연구는
test 가 균형잡혀 있다고 보고 tau > 0 으로 경계를 희소 클래스 쪽으로 미는데,
우리 test 는 none 93.3% 로 train(67.4%)보다 **더** 쏠려 있어 방향이 반대다.
게다가 오프셋을 log(prior) 방향 한 축으로만 움직여 자유도가 부족하다.

**val 튜닝이 해로운 이유.** 이론적 설명이 있다. test 의 93.3% 가 none 이므로
none 에서 오탐률이 0.3% 만 생겨도 결함 클래스의 precision 이 무너진다.
따라서 test 에서 macro-F1 을 최대화하는 결정 규칙은 val 에서보다 결함 예측에
**더 보수적**이어야 하는데, val(none 67.4%)에서 튜닝하면 정반대로 밀린다.
E3 의 Edge-Ring recall 0.930 / precision 0.250 이 이 현상의 실물이다.

**재가중이 통한 이유.** val 표본에 w_y = q_target(y) / p_val(y) 를 곱하면
val 라벨만으로 "타겟 분포에서의 macro-F1" 을 근사하게 된다.
타겟 사전확률은 모델이 라벨 없는 test 에 매긴 예측 빈도(classify-and-count)로 추정했고,
none 0.928 추정 대 0.933 실제로 오차 0.005 였다. **test 라벨은 최종 평가에만 썼다.**

이 경로의 남은 여지는 0.6851 대 oracle 0.6974 로 0.012 다.

## 다음 — 수렴이 더 큰 지렛대다

문헌 조사 결과, 9-class WM-811K 에서 불균형 기법을 의도적으로 쓰지 않은 논문이
macro-F1 0.9098 을, ResNet-18 이 0.895 를 보고한다. 다만 **대부분 자체 랜덤 분할**이라
우리 공식 split 수치와 직접 비교할 수 없다. 실제로 우리 val 은 0.8922 로 그 대역 안이다.

직접 비교 가능한 부분은 학습량이다. 우리 2,520 step 은 레퍼런스 구현의 약 15% 이고
15 epoch 에서 loss 가 계속 내려가는 중이었다. **미수렴 상태의 기법 비교는 잠정적이다.**
E6(focal 40 epoch, cosine, seed 2개), E7(plain CE 40/80 epoch)을 실행 중이다.

또한 문헌의 병목 클래스가 Edge-Loc(5,189장), Loc(3,593장), Scratch(1,193장)로
**희귀 클래스가 아니라 중간 빈도**라는 점이 우리 관측(Loc, Scratch 최저)과 일치한다.
이는 병목이 불균형이 아니라 클래스 간 의미적 혼동일 가능성을 시사하며,
그렇다면 재가중 계열로는 한계가 있다.

# 3차 사이클 — 수렴 (2026-08-21)

## 40 epoch 이 지금까지의 모든 기법을 합친 것보다 컸다

E5 와 동일한 구성(focal gamma=2, dihedral 증강)에서 epoch 만 15 에서 40 으로 늘리고
cosine 스케줄과 warmup 3 을 붙였다.

| | val macro-F1 | test macro-F1 | test accuracy |
|---|---:|---:|---:|
| E5 (15 epoch, 고정 lr) | 0.8922 | 0.6705 | 0.9555 |
| **E6 (40 epoch, cosine)** | **0.9452** | **0.7251** | 0.9589 |

**+0.0546.** 비교하자면 증강이 +0.101, class weight 가 +0.099, focal 이 +0.016,
재가중 오프셋이 +0.015 였다. 손실 설계를 바꾸는 것보다 충분히 학습시키는 것이 컸다.

### 클래스별 (test F1)

| 클래스 | support | E5 | E6 | 변화 |
|---|---:|---:|---:|---:|
| none | 110,701 | 0.982 | 0.982 | 0 |
| Center | 832 | 0.488 | 0.615 | **+0.127** |
| Donut | 146 | 0.623 | 0.634 | +0.011 |
| Edge-Loc | 2,772 | 0.650 | 0.632 | -0.018 |
| Edge-Ring | 1,126 | 0.766 | 0.764 | -0.002 |
| Loc | 1,973 | 0.577 | 0.605 | +0.028 |
| Random | 257 | 0.644 | 0.745 | **+0.101** |
| Scratch | 693 | 0.477 | 0.605 | **+0.128** |
| Near-full | 95 | 0.827 | 0.944 | **+0.117** |

가장 나빴던 Scratch 가 가장 크게 올랐다. Edge-Loc 만 소폭 뒤로 갔다.

### 수렴 확인

| epoch | loss | val macro-F1 |
|---:|---:|---:|
| 1 | 0.1496 | 0.5666 |
| 10 | 0.0224 | 0.8820 |
| 20 | 0.0110 | 0.9134 |
| 30 | 0.0037 | 0.9372 |
| 35 | 0.0021 | 0.9435 |
| 40 | 0.0015 | 0.9447 |

ep35 에서 ep40 사이 val 증가폭이 0.0012 로 평평해졌고 loss 는 0.0015 로 암기 수준이다.
**40 epoch 는 거의 수렴점**이다. 80 epoch(E7b)로 남은 여지를 확인 중이다.

### 함의

1차, 2차 사이클의 기법 비교는 전부 **미수렴 상태에서 이뤄졌으므로 잠정적이다.**
특히 "증강과 class weight 가 겹친다", "focal 이 class weight 를 대체한다" 같은 결론은
수렴 후 재검증이 필요하다. 진행 중인 E7(plain CE 40/80 epoch)이 그 대조군이다.

한편 val 0.9452 는 문헌이 보고하는 대역(0.84~0.93) 안이다. test 0.7251 과의 격차 0.22 는
여전히 분포 이동에서 온다. 이 격차는 학습으로 좁혀지지 않는 부분이다.


## run-to-run 분산 — 실험 해석의 기준선

같은 설정을 seed 만 바꿔 두 번 돌렸다.

| seed | val macro-F1 | test macro-F1 | test accuracy |
|---|---:|---:|---:|
| 0 | 0.9452 | 0.7251 | 0.9589 |
| 1 | 0.9451 | 0.7340 | 0.9629 |
| 차이 | 0.0001 | **+0.0089** | +0.0040 |

**val 은 사실상 동일한데 test 는 0.0089 벌어진다.**
학습을 다시 돌려서 비교하는 경우 이 정도 차이는 잡음이다.

이 기준으로 앞선 결론들을 다시 보면,

- E5 focal(0.6705) 대 E4b(0.6545)의 +0.016 은 잡음 경계에 가깝다. focal 이 낫다는 결론은 약하다.
- 반면 **재가중 오프셋의 +0.0146 은 성격이 다르다.** 같은 체크포인트에 결정 규칙만 바꾼
  짝지은 비교라 학습 분산이 개입하지 않는다. 이쪽은 유효하다.

**앞으로 설정 비교는 최소 2 seed 로 하고, 단일 실행 차이로 결론짓지 않는다.**
