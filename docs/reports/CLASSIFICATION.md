# 분류 성능 현황 (WM-811K 9-class)

**현재 상태를 담는 문서다.** 사이클별 경위는
[experiments/details/cycle_log.md](../experiments/details/cycle_log.md) 에 있다.

주 지표는 **공식 test split(118,595장, none 93.3%)의 macro-F1**.
val 은 체크포인트 선택에만 쓴다. 갱신일 2026-08-22.

| **test accuracy** | **0.9640** |

## 무엇이 통했고 무엇이 통하지 않았는가

### 통한 것 (둘뿐이다)

| 기법 | 이득 | 근거 |
|---|---:|---|
| **dihedral 증강** | +0.101 | 웨이퍼의 회전 대칭성에 맞는 사전지식 |
| **수렴** (15 -> 40 epoch) | +0.055 | 이 둘만이 seed 분산(범위 0.050)을 넘는다 |

### 판정 보류 (측정 정밀도 부족)

seed 분산이 0.050 이라 아래 차이들은 단일 실행 비교로는 부호조차 확정할 수 없다.
이전 판(2026-08-22 이전)에서 "통한 것"으로 적었던 항목이 여기로 내려왔다.

| 기법 | 관측된 차이 | 상태 |
|---|---:|---|
| **pad 입력 표현** | 단일 실행 +0.022 | **3 seed 평균은 -0.003** (0.7261 vs resize focal 0.7295). 이득 없음 쪽으로 기운다 |
| 앙상블 (resize 3개) | +0.009 | 잡음의 1/5. pad 3 seed 앙상블 결과 대기 중 |
| resize 96 | +0.005 | 잡음의 1/10 |
| focal vs CE (수렴 후) | +0.003 | 잡음의 1/17 |
| 80 epoch | -0.018 | 잡음의 1/3. 스케줄 길이 교란도 있다 |

### 통하지 않은 것

| 기법 | 결과 | 이유 |
|---|---:|---|
| 역빈도 class weight | 미수렴 시 +0.099, 수렴 후 무의미 | 극소수 클래스 가중치 106.7 로 gradient 분산 폭증 |
| focal loss | 수렴 후 CE 와 차이 0.0027 | 샘플 단위 조정이라 클래스 불균형을 직접 다루지 않음 |
| focal + alpha | -0.089 | 같은 축을 두 번 조작해 과잉 이동 |
| gradient clipping | -0.064 | 불안정이 성능의 주 원인이 아니었다 |
| 스칼라 logit adjustment | +0.0007 | 최적 tau 가 -0.05 로 0 근처. 표준 long-tail 과 방향이 반대 |
| 클래스별 오프셋 (val 튜닝) | -0.015 | val 이 학습 분포라 test 최적 경계와 반대로 밀린다 |
| 타겟 재가중 오프셋 | 미수렴 +0.015, 수렴 -0.039 | 경계가 잘못 놓인 모델만 도움 |
| **BN 통계 타겟 적응** | **-0.295** | covariate shift 용 기법인데 우리 이동은 label shift |

이 중 잡음보다 확실히 큰 실패는 focal+alpha(-0.089), grad clip(-0.064), 타겟 재가중 오프셋(-0.039),
BN 적응(-0.295) 넷이다. 나머지는 "이득이 없다"까지만 말할 수 있고 "해롭다"고는 말할 수 없다.

## seed 분산이 지금까지의 비교 대부분을 무효화한다

E10 은 E8(pad, 0.7485)을 seed 만 바꿔 두 번 반복했다. config diff 는 `seed: 0 -> 1/2` 와 tag 뿐이다.

| 설정 | seed 수 | 값 | 평균 | 범위 | 표준편차 |
|---|---:|---|---:|---:|---:|
| pad 64 | 3 | 0.7485 / 0.6991 / 0.7308 | 0.7261 | **0.0495** | 0.0251 |
| resize 64 focal | 2 | 0.7251 / 0.7340 | 0.7295 | 0.0089 | 0.0063 |

**기존 잡음 기준선 0.0089 는 n=2 에서 나온 과소추정이었다.** 실제 범위는 그 5.6배다.
결과적으로 이 문서가 기록한 차이 중 **+0.055(수렴)과 +0.101(증강)을 뺀 전부가 잡음 범위 안**이다.
앞으로 설정 비교는 **최소 3 seed** 로 하고, 단일 실행 최고치는 기록하되 결론의 근거로 쓰지 않는다.

### 분산은 고르게 퍼져 있지 않고 두 클래스에 몰려 있다

pad 3 seed 의 클래스별 F1 범위다.

| 클래스 | seed 0 | seed 1 | seed 2 | 범위 |
|---|---:|---:|---:|---:|
| **Scratch** | 0.613 | **0.280** | 0.608 | **0.334** |
| Near-full | 0.920 | 0.927 | **0.797** | 0.130 |
| Edge-Loc | 0.677 | 0.583 | 0.655 | 0.094 |
| 나머지 6개 | | | | ≤ 0.033 |

macro-F1 이 9개 클래스의 단순 평균이므로 Scratch 하나가 0.334 흔들리면 macro 가 0.037 흔들린다.
관측된 macro 범위 0.0495 의 3/4 이 이 한 클래스에서 나온다.

### 그 분산의 정체는 표현이 아니라 none 누출이다

Scratch 가 무너진 seed 1 에서 **recall 은 멀쩡했다.**

| | seed 0 | seed 1 | seed 2 |
|---|---:|---:|---:|
| Scratch recall | 0.683 | 0.649 | 0.538 |
| Scratch **precision** | 0.557 | **0.178** | 0.699 |
| none -> Scratch 오검출 | 292 | **2,007** | 115 |

Scratch 참값은 693 장인데 none 은 110,701 장이다. none 의 오분류 중 **1.8% 가 Scratch 로 향하면
그것만으로 참값의 3배**가 되어 precision 이 무너진다. 모델이 Scratch 를 못 배운 것이 아니라,
none 의 오차가 어느 클래스로 흘러가느냐가 seed 마다 다른 것이다.

### 같은 구조가 모든 병목 클래스에 적용된다

수렴한 6개 실행에서, none 이 새어 들어가는 양과 precision 이 정확히 대응한다.

| 클래스 | 참값 | none -> 이 클래스 (6개 실행 범위) | precision 범위 |
|---|---:|---:|---:|
| Near-full | 95 | **0** | 0.868 ~ 0.935 |
| Donut | 146 | 3 ~ 12 | 0.645 ~ 0.731 |
| Random | 257 | 6 ~ 18 | 0.744 ~ 0.796 |
| Edge-Ring | 1,126 | 59 ~ 147 | 0.779 ~ 0.866 |
| Center | 832 | 163 ~ 419 | 0.532 ~ 0.700 |
| Loc | 1,973 | 187 ~ 425 | 0.652 ~ 0.740 |
| Edge-Loc | 2,772 | 1,029 ~ 2,158 | **0.473 ~ 0.628** |
| Scratch | 693 | 109 ~ 2,007 | **0.178 ~ 0.699** |

recall 은 이미 대부분 0.54 ~ 0.78 로 고르다. **격차는 precision 쪽에 있고, precision 은
none 110,701 장의 2~5% 오차가 어디로 배분되는지가 결정한다.**

이것이 지금까지 실패한 기법들을 한 줄로 설명한다. class weight, focal, focal+alpha,
logit adjustment, per-class offset 은 전부 결정 경계를 **소수 클래스 쪽으로 미는** 같은 축을 조작한다.
그 방향은 none 누출을 **늘린다.** test 에서 필요한 방향은 반대다(test 는 train 보다 none 이 더 많다).
스칼라 logit adjustment 의 최적 tau 가 -0.05 로 음수였던 것이 이 방향과 일치한다.

## 이 프로젝트의 네 가지 교훈

**0. 잡음 기준선을 먼저, 그리고 충분한 표본으로 재라.** 이 프로젝트가 가장 크게 틀린 지점이다.
n=2 로 잰 0.0089 를 기준선으로 삼은 탓에 잡음인 차이를 8 사이클 동안 결론으로 기록했다.
기준선이 틀리면 그 뒤의 모든 비교가 틀린다. 기법을 하나 시험할 비용으로 seed 를 하나 더 도는 편이
거의 항상 낫다.


**1. 미수렴 상태에서 측정한 기법 이득은 수렴 후 살아남지 않는다.** 예외가 없었다.
focal, class weight, 사후 보정 전부 그랬다. 수렴을 먼저 확보하고 기법을 비교해야 한다.
순서를 뒤집으면 사라질 차이를 쫓게 된다.

**2. val 을 믿을 수 없다.** val 은 Training 분포(none 67.4%)를 물려받고 test 는 93.3% 다.
val 이 방향을 잘못 알려준 사례가 셋이다.

| 변경 | val | test |
|---|---:|---:|
| dihedral 증강 | +0.016 | +0.101 (과소평가) |
| class weight | -0.007 | +0.099 (부호 반대) |
| 80 epoch | +0.003 | -0.018 (부호 반대) |

**단 구분이 필요하다.** E9 에폭 곡선에서 val 이 고른 epoch 50 의 test 는 0.7129,
실제 최적 epoch 55 는 0.7191 로 차이가 0.0062 다. 잡음 기준선 안이다.
**한 실행 안에서 체크포인트를 고르는 데는 val 이 쓸 만하다.**

**E10 이 실패 범위를 넓혔다.** val 은 설정 간 비교뿐 아니라 **같은 설정의 seed 간 비교**에서도 실패한다.

| pad seed | best val macro-F1 | test macro-F1 |
|---:|---:|---:|
| 0 | 0.9361 | **0.7485** |
| 1 | **0.9401** | 0.6991 |
| 2 | 0.9357 | 0.7308 |

val 이 가장 높은 seed 1 이 test 가 가장 낮다. **val 로 seed 를 고르면 최악을 고른다.**
val 이 성립하는 범위는 이제 "한 실행 안에서 epoch 고르기" 하나로 좁혀졌다.

**3. 대조군 없이는 원인을 알 수 없다.** BN 적응이 이를 잘 보여준다.
test 로 재추정하면 -0.295, val 로 재추정하면 -0.016 이다. 대조군이 없었다면
"BN 적응은 안 통한다" 에서 멈췄을 것이다. 지금은 클래스 구성이 통계를 오염시킨다는
메커니즘을 알고, 따라서 클래스 구성이 유지되는 이동이라면 같은 기법이 유효할 수 있다는 것도 안다.

## 방법론 기준선

- **run-to-run 범위 0.050, 표준편차 0.025** (pad 3 seed). **이보다 작은 차이는 잡음이다.**
  설정 비교는 **최소 3 seed** 로 하고 평균과 범위를 함께 적는다.
  (이전 판의 0.0089 는 n=2 과소추정이었다.)
- 클래스별 수치는 훨씬 더 흔들린다. Scratch 범위 0.334, Near-full 0.130, Edge-Loc 0.094.
  **클래스별 F1 의 단일 실행 비교는 하지 않는다.**
- 같은 체크포인트에 결정 규칙만 바꾸는 짝지은 비교는 학습 분산이 없어 더 신뢰할 수 있다.

## 문헌 대비

9-class WM-811K 의 공개 수치는 macro-F1 0.84~0.93 대역이지만 **대부분 자체 랜덤 분할**이다.
우리 val 0.946 이 그 대역 안이고, 공식 split test 0.749 와의 격차 0.20 이 분포 이동의 크기다.
98% 이상 수치는 balanced 파생 벤치마크이거나 none 을 뺀 8-class 조건이라 비교 대상이 아니다.

## 에폭 곡선 (E9, resize 64 기준)

5 epoch 마다 스냅샷을 남기고 전부 test 로 평가했다. 60 epoch cosine 스케줄이다.

| epoch | val macro-F1 | test macro-F1 | test accuracy |
|---:|---:|---:|---:|
| 5 | 0.8026 | 0.5400 | 0.8881 |
| 10 | 0.8738 | 0.6244 | 0.9194 |
| 15 | 0.9108 | 0.6520 | 0.9481 |
| 20 | 0.9223 | 0.6825 | 0.9573 |
| 25 | 0.9167 | 0.6620 | 0.9474 |
| 30 | 0.9299 | 0.6948 | 0.9410 |
| 35 | 0.9337 | 0.6732 | 0.9309 |
| 40 | 0.9289 | 0.7046 | 0.9546 |
| 45 | 0.9412 | 0.7146 | 0.9565 |
| 50 | 0.9498 | 0.7129 | 0.9547 |
| 55 | 0.9445 | 0.7191 | 0.9571 |
| 60 | 0.9437 | 0.7174 | 0.9565 |

val 최고는 epoch 50, test 최고는 epoch 55 이고 그 차이는 0.0062 로 잡음 안이다.
test 는 epoch 45 부근부터 평평해진다.

### 이 곡선이 앞선 결론을 정정한다

**"80 epoch 가 40 보다 나쁘다" 의 원인은 학습량이 아니라 스케줄이다.**
E7(40 epoch)과 E7b(80 epoch)는 cosine 길이가 달라 lr 궤적 자체가 다르다.
40-epoch 런은 40 에서 lr 이 0 으로 감쇠하지만 80-epoch 런은 그 시점에 아직 높다.

E9 가 이를 드러낸다. 60-epoch 런의 epoch 40 스냅샷은 0.7046 인데,
같은 40 epoch 를 스케줄 끝까지 돈 E7 은 0.7269 다. **차이는 lr 이 끝까지 감쇠했는지 여부다.**

스케줄 길이별로는 40 -> 0.7269, 60 -> 0.7191, 80 -> 0.7088 로 완만히 내려가지만
간격이 잡음 근처라 "길수록 나쁘다" 고 단정하기 어렵다.
확실한 것은 **cosine 을 끝까지 감쇠시키는 것이 중요하다** 는 것이다.

## 남은 후보

none 누출이 병목이라는 진단에서 나오는 순서다.

1. **none-vs-결함 2단계 계층 분류.** 1단계에서 110,701 장의 누출을 명시적 임계값 하나로 통제하고,
   2단계는 결함만 8-way 로 푼다. 결함 사전확률이 train 32.6% -> test 6.7% 로 4.9배 이동하는데
   현재 flat 9-way softmax 는 이 이동과 결함 구성 이동을 한 덩어리로 섞고 있다.
   결함만 보면 불균형도 완만하다(최대/최소 비 150 대 9-way 의 648).
   대조군 두 개가 필요하다 — (a) 임계값 보정 없는 2단계로 "구조" 자체의 효과를 재고,
   (b) 같은 예산의 flat 9-way 로 용량 효과를 배제한다.
2. **분산 자체를 줄이기.** Scratch 하나가 macro 분산의 3/4 을 만든다. 앙상블은
   원리상 여기에 맞는 도구다(seed 별 누출 패턴이 상쇄된다). pad 3 seed 앙상블 결과가 이를 시험한다.
3. 웨이퍼 크기 버킷별 층화 평가와 크기 조건부 결정 규칙
4. 라벨 노이즈 검토 — none 중 실제로는 희미한 결함이 있는 것이 얼마나 되는지. (미검증)
