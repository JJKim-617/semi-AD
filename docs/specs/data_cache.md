# 데이터 캐시 사양 — wm811k_64.npz

원본 `LSWMD.pkl`(2.0GB, 811,457행)을 고정 크기 uint8 텐서 캐시로 변환.

## 실행
```bash
./exe/a1_preprocess_wm811k.sh                      # 64x64 (기본)
./exe/a1_preprocess_wm811k.sh configs/wm811k_32.yaml
python3 src/a1_preprocess_wm811k.py --size 96 --mode pad --tag wm811k_96pad
```

## 설계 결정
- **리사이즈는 nearest-neighbor 고정.** 셀 값이 명목형(0=die 없음, 1=정상, 2=불량)이라
  bilinear 등 보간은 1.5 같은 존재하지 않는 값을 만든다.
- **기본 64x64.** WM-811K 문헌의 사실상 표준(비교 가능성). 원본 최빈 크기는 26x26(38%),
  33x29(21%) 로 대부분 64보다 작아 업샘플링이 된다. 경량 실험은 32 로 충분.
- **`mode: pad` 옵션 제공.** 리사이즈는 웨이퍼의 물리적 크기 정보를 잃는다. 중앙 배치 +
  0 패딩으로 크기를 보존하는 대안을 파라미터로 남겨 둠.
- **라벨 기본 제외 없음**: `labeled_only=true` 로 172,950장만 저장.
  미라벨 638,507장은 `--include-unlabeled` 로 (자기지도/준지도용).
- 원본 컬럼명은 `trianTestLabel` (데이터셋 자체 오타). 그대로 참조한다.
