# 국소 불량 밀도 입력 채널 (E20)

**작성 시각 2026-08-23 01:35 KST — 아래 "판정 기준" 은 한 줄도 실행 전에 적었다.**

## 왜

지금 모델의 입력은 one-hot 3채널(다이없음/정상/불량)뿐이다. **"국소적으로 몰려 있는가"
를 conv 가 스스로 배워야 한다.**

옆 워크스트림(`../Semi-AD-OOD`, 읽기만 함)이 오늘 밝힌 것이 이것을 직접 겨냥한다.
**학습이 전혀 없는 국소 밀도** — 각 다이 위치에서 kxk 창 안 불량 비율의 최대 —
하나만으로 정상/결함을 **AUROC 0.9206 / AUPR 0.7143** 으로 가른다.
k=3 은 0.3845 로 전역 불량률과 같고 **k=5(0.6785), k=7(0.7143) 에서만 이득이 난다.**

핵심은 이것이다. **정상 웨이퍼도 불량 다이가 중앙값 80개(약 10%) 있다.
결함은 개수가 아니라 배치로 정의된다.** Scratch 는 중앙 불량 비율 0.0917 로
정상 0.0983 보다 **오히려 낮다.** 개수로는 원리적으로 구분이 불가능하다.

우리 병목과 정확히 맞물린다 — 전체 오류의 **81.7% 가 none 과 결함의 경계**에 있고
(결함->none 44.5%, none->결함 37.2%), 클래스별로는 Scratch(F1 0.710)와
Edge-Loc(0.758)이 최하위다. 둘 다 "몇 개인가" 가 아니라 "어떻게 놓였는가" 로 정의되는 결함이다.

**하이퍼파라미터 튜닝이 아니라 입력 표현의 구조적 변경이다.** lr/batch/epoch 는 건드리지 않는다.

## 설계

입력을 **3채널 -> 5채널**로 바꾼다. one-hot 3채널 뒤에 밀도 맵 2장을 붙인다.

| 채널 | 내용 |
|---:|---|
| 0,1,2 | 기존 one-hot (다이없음 / 정상 / 불량) |
| 3 | 5x5 창 안 불량 다이 비율 (다이 없는 칸은 0) |
| 4 | 7x7 창 안 불량 다이 비율 |

창 안의 **다이 개수로 나눈다**(창 넓이가 아니라). 그래서 웨이퍼 가장자리에서 희석되지 않고
비율이라 웨이퍼 크기에 자동으로 불변이다. 계산식은 OOD 쪽 `a24_ood_residual.
local_fail_density_map` 과 같고 코드는 복사해 왔다(그쪽 worktree 는 건드리지 않았다).

나머지는 `configs/cls_e17.yaml` 과 **완전히 동일**하다 —
pad64 캐시, dihedral + translate 증강, ResNet-18(stem 3x3 s1, maxpool 제거),
Adam 1e-3, batch 256, 40 epoch, cosine + warmup 3.
config diff 는 `density_ks`, `tag`, `seed` 뿐이다.

밀도는 **증강을 건 뒤에** 계산한다. dihedral 과 translate 는 둘 다 밀도 맵과 교환되므로
(정사각 창 + 상수 패딩이라 rot90/flip/shift 에 정확히 등변) 순서가 결과를 바꾸지는 않지만,
증강 뒤 계산이 정의상 항상 옳다. 같은 이유로 **TTA 도 그대로 성립한다.**

## 대조군 둘

1. **채널 없음** — `e17_translate_s0~s3` 4 seed(평균 **0.7645**, 범위 0.0067)를 그대로 쓴다.
   재학습하지 않는다. config diff 가 `density_ks` 와 tag/seed 뿐이라 정당하다.
2. **밀도 셔플** — 5채널 구조는 같은데 **밀도 채널을 다른 웨이퍼에서 가져온다**(무작위 순열).
   채널 수, 파라미터 수, 채널별 통계가 전부 보존되고 **one-hot 과의 대응만 깨진다.**
   E11 에서 "크기 정보" 의 효과를 크기 값 셔플로 갈랐던 것과 같은 대조군이다.
   **이게 없으면 이득이 정보 때문인지 용량 때문인지 못 가린다.**

## 판정 기준 (실행 전에 박는다)

주 기준은 **앙상블 기여(leave-one-out)** 다. 단독 성능이 아니다(작업 원칙 6).
비교 풀은 `e17_translate_s0~s3` 4개 + 밀도 3 seed 로 고정한다 —
16차에서 풀에 강한 모델이 몰려 품질을 다양성으로 착각한 교란이 있었으므로,
**같은 config 에서 나온 모델끼리만 넣어 품질을 맞춘다.**

| 결과 | 조건 |
|---|---|
| **채택** | 밀도 3 seed 의 LOO 평균이 **+0.005 이상** 이고, 같은 풀에서 **셔플 대조군보다 높다** |
| **기각** | LOO 평균이 **+0.003 미만** (= `e8_res96` 의 +0.0025 수준. 이미 있는 표현을 하나 더 넣는 것과 구분 불가) |
| **판정 보류** | 그 사이(+0.003 ~ +0.005) |

부차 기준(단독 성능)은 **판정에 쓰지 않는다.** 3 seed 평균과 범위를 대조군 0.7645/0.0067 과
나란히 적기만 한다. 잡음 기준선이 0.0495 이므로 단독 3 seed 평균의 차이가 그보다 작으면
그 자체로는 아무 말도 하지 않는다.

## 메커니즘 확인 — 이득이 나오면 먼저 교란을 찾는다 (원칙 7)

설명이 옳다면 다음이 **같이** 나와야 한다.

1. **none -> 결함 누출이 준다.** 대조군 translate 모델의 누출과 짝지어 비교한다.
2. **Scratch 와 Edge-Loc 의 F1 이 가장 크게 오른다.** 둘이 병목이고 둘 다 국소 뭉침으로 정의된다.
3. **셔플 대조군은 오르지 않는다.**

**macro-F1 은 올랐는데 누출이 안 줄거나 셔플도 같이 오르면 설명이 틀린 것이다.**
그때는 채택하지 않고 교란을 찾는다.

## 미리 하는 예측 (틀리면 그대로 기록한다)

- k=5 보다 k=7 이 더 유용할 것이다. OOD 쪽에서 AUPR 0.6785 < 0.7143 이었다.
- **크기 구간별 오검출률이 평평해야 한다.** 극좌표(E15b)는 웨이퍼 크기를 표현 자체에
  새겨 넣어 못 본 크기에서 0.4~0.5 로 무너졌다. 밀도는 **비율**이고 pad 표현은
  원본 픽셀 스케일을 유지하므로 kxk 창이 물리적으로 일정한 범위를 덮는다 —
  원리적으로는 크기 의존이 없어야 한다. **그래도 확인한다.** 이 예측이 깨지면
  극좌표와 같은 실패 모드다.
- Scratch 의 seed 분산(범위 0.334)이 줄어들 것이다. Scratch 붕괴가 macro 분산의 3/4 을 만든다.
  단 **분산이 줄어도 평균이 안 오르면 채택하지 않는다** — 이 프로젝트에서 그 조합이
  이미 세 번(자기지도, 추가 증강, EMA) 나왔고 전부 기각됐다.

**그런데 우리 앙상블이 같은 이진 과제에서 AUROC 0.9807 / AUPR 0.9038 로 훨씬 세다.**
그러므로 밀도가 값어치가 있으려면 앙상블이 못 보는 것을 봐야 한다.

앙상블(TTA 18개)의 오류 위에서 밀도가 어느 쪽을 가리키는지 쟀다.

| 밀도 | FP 대 TN | FN 대 TP | FP 대 FN |
|---|---:|---:|---:|
| k=5 | **0.8806** | **0.2126** | 0.3766 |
| k=7 | 0.8663 | 0.2329 | 0.4490 |

**앙상블의 오검출(FP)은 밀도도 높고, 놓친 결함(FN)은 밀도도 낮다. 같은 편이다.**
경계 오류는 모델이 국소 밀도를 못 계산해서 생긴 것이 아니라, **국소 밀도 자체가
그 웨이퍼들에서 틀린 쪽을 가리켜서** 생긴다.

**따라서 이 진단은 채택 쪽이 아니라 기각 쪽을 예측한다.** 사전 등록한 판정 기준은
바꾸지 않는다. 다만 이 진단이 배제하지 못하는 경로가 둘 남아 있다 —
(1) 채널은 스칼라가 아니라 맵이라 결함끼리의 구분에 쓸 정보가 더 있을 수 있고,
(2) 단독으로 못 올려도 앙상블 다양성으로는 기여할 수 있다(e8_res96 이 그랬다).

### 사전 약속 — 셔플 대조군을 언제 포기하는가 (서버 01:52, test 결과 0건인 시점)

**이 절은 E20 의 test 수치가 하나도 나오기 전에 적었다.** `result/cls_baseline/` 에
`e20_*_test.json` 이 아직 없다(체크포인트만 있다).

셔플 대조군은 **채택 분기에서만** 쓸모가 있다 — "이득이 정보 때문인가 용량 때문인가" 를
가르는 것이라, **이득이 없으면 가를 것이 없다.** GPU 는 0번 하나뿐이고 남은 슬롯도 하나뿐이다.

그래서 규칙을 지금 박는다.

> 밀도 3 seed 가 끝나면 셔플 없이 먼저 LOO 를 잰다.
> **LOO 평균이 +0.005 미만이면 채택 분기가 이미 닫힌 것이므로 셔플 대조군을 돌리지 않고,
> 그 GPU 슬롯을 E21(선 필터 채널)에 쓴다.** +0.005 이상이면 예정대로 셔플을 돌린다.

이렇게 하는 이유는 오늘 새로 나온 것 때문이다 — **온전한 창만 보는 선 필터가
Scratch 대 none 을 AUROC 0.9204 로 가른다**(정사각 창 0.7121). 학습이 0 이다.
Scratch 는 지금 F1 0.710 으로 병목이고 **밀도로는 원리적으로 안 잡히는** 클래스다.
상세는 [research/local_density/README.md](../../research/local_density/README.md).

위 규칙은 **실행이 불가능하다.** GPU 가 비는 시점과 LOO 를 잴 수 있는 시점이 어긋난다.

- 그런데 3 seed LOO 는 `dens_s2` 가 끝나는 04:20 이후에야 잴 수 있다.
  그 시점에 55분짜리를 새로 띄우면 마감(06:30)을 못 지킨다.

그래서 고친다. **03:15 에, 그때 가진 밀도 seed(s0, s1)로 LOO 를 재고 그것으로 고른다.**

> **2 seed LOO 평균이 +0.005 이상이면 셔플 대조군, 미만이면 E21(선 필터 채널)** 을
> `dens_s2` 와 나란히 띄운다.

2 seed 는 3 seed 보다 약한 근거다. 그것을 감수하는 이유를 적어 둔다 —
**이건 판정이 아니라 남은 GPU 슬롯 하나를 어디에 쓸지 고르는 결정**이고,
E20 의 판정 자체는 예정대로 3 seed LOO 로 한다. 셔플을 못 돌리면
"용량 대 정보" 를 못 가른 채로 판정하게 되는데, 그건 **채택 분기에서만 문제**다.
기각 분기에서는 가를 것이 없다.

### 첫 seed 와, 그것을 설명할 두 번째 가설 (서버 02:30, s1/s2 아직 없음)

`e20_dens_s0` = **0.7706 / 0.9715**. 대조군 4 seed 는 0.7674 / 0.7660 / 0.7640 / 0.7607
(평균 0.7645, 범위 0.0067)이므로 **대조군 범위 전체를 넘었다.** 사전 진단은 기각을
예측했는데 첫 seed 는 반대다.

**그런데 사전 등록한 메커니즘 서명이 안 나왔다.**

| | 대조군 4 seed | 밀도 s0 | 판정 |
|---|---:|---:|---|
| none -> 결함 누출 | 평균 1,190 (범위 875~1,527) | **1,067** | 대조군 범위 **안** |
| Scratch F1 | 0.695 (범위 0.026) | 0.702 | 범위 안 |
| Edge-Loc F1 | 0.742 (범위 0.022) | 0.744 | 범위 안 |
| 나머지 6개 | | | 전부 범위 안 |

**어느 클래스도 두드러지지 않는다.** 이득이 있다면 아홉 클래스에 얇게 퍼져 있다.
사전 등록한 예측(Scratch, Edge-Loc 이 가장 크게 오른다)이 **s0 에서는 틀렸다.**

그래서 두 번째 가설을 **지금(s1, s2 나오기 전에) 적어 둔다.**

> **가설 B: 밀도 채널이 한 일은 경계를 고친 것이 아니라 표현을 하나 더 만든 것이다.**
> `e8_res96` 처럼 새 다양성 축으로 작동한다는 뜻이다.

가설 B 가 맞다면 이렇게 나와야 한다.
1. LOO 기여가 **양수**다 (그래서 채택 분기로 갈 수 있다).
2. 그런데 **누출이 안 준다** — 대조군 범위 안에 머문다.
3. 클래스별 이득이 **한 곳에 몰리지 않고 고르게 퍼진다.**

가설 A(경계를 고친다)가 맞다면 2번과 3번이 반대여야 한다.
**s0 는 이미 2번과 3번에서 가설 B 쪽이다.** s1, s2 로 확인한다.

두 가설은 **채택/기각 판정을 바꾸지 않는다**(판정은 LOO 하나로 한다).
바꾸는 것은 **보고서에 무엇이라고 쓰느냐**다 —
"국소 밀도가 경계를 고친다" 와 "채널을 늘리면 표현이 하나 더 생긴다" 는 전혀 다른 주장이고,
후자라면 굳이 밀도일 이유가 없다(셔플 대조군이 그것을 가른다).

### 그 사전 진단을 취소한다 (서버 02:50, s1/s2 아직 없음)

위 "실행 전 진단" 은 `FP 대 TN 0.8806`, `FN 대 TP 0.2126` 을 근거로 **기각을 예측**했다.
**그 비교가 교란돼 있었다.** 모델의 예측으로 조건을 걸어 선택 효과가 섞인다 —
같은 비교에서 모델 자신의 점수가 0.9999 / 0.0008 로 나오는 것이 그 증거다.

선택을 맞춰(FP 대 TP, FN 대 TN) 다시 재고 모델 확신도로 층화하면 이렇다.

| 신호 | FP 대 TP | FN 대 TN | 층화 후 FP 대 TP | 층화 후 FN 대 TN |
|---|---:|---:|---:|---:|
| 국소 밀도 k=5 | **0.3143** | **0.8416** | 0.4962 | **0.8230** |
| 선 L=11 온전창 | **0.2338** | **0.8566** | **0.3843** | **0.8488** |

**밀도는 놓친 결함 방향에 모델 확신도 위로 0.82 를 남긴다.**
스칼라 결정 규칙으로는 못 쓰지만(오라클 w=0), **채널로 주는 경로는 이것이 배제되지 않는다.**

**따라서 사전 진단의 예측을 바꾼다 — 기각 예측을 철회한다.**
사전 등록한 판정 기준(LOO)은 그대로 두고, **예측을 "모르겠다" 로 내린다.**
상세는 [research/local_density/](../../research/local_density/README.md) 의 정정 절.

| | 값 |
|---|---|
| 밀도 단독 (2 seed) | **0.7706, 0.7721** (평균 0.7713, 범위 0.0015) |
| 대조군 translate (4 seed) | 0.7674, 0.7660, 0.7640, 0.7607 (평균 0.7645, 범위 0.0067) |
| 밀도 2개 앙상블 | 0.7754 |
| 대조군 4개 앙상블 | **0.7755** |
| 대조군 + 밀도 6개 | 0.7760 |
| **LOO 군 평균 (밀도)** | **+0.0002** |

**밀도 모델이 단독으로는 대조군 네 개를 전부 넘는데(최저 0.7706 > 최고 0.7674),
앙상블로는 같은 자리에 온다(0.7754 대 0.7755).** LOO 도 0 이다.

사전 약속은 "LOO < +0.005 면 셔플 대조군을 버리고 E21 에 슬롯을 쓴다" 였다.
**그 약속의 전제가 틀렸다.** 전제는 "이득이 없으면 셔플이 가를 것이 없다" 였는데,
**이득이 없는 게 아니라 다른 축에 있었다** — 단독 성능이 깨끗하게 올랐고
(두 분포가 겹치지 않는다) 그것이 정보 때문인지 채널 수 때문인지는 아직 안 갈렸다.

**그래서 셔플 대조군을 돌린다.** E21 학습은 이번 사이클에 하지 않는다
(사전 등록과 학습 없는 진단만 남긴다).

이 결정은 **숫자가 예쁜 쪽을 고른 것이 아니다.** 판정 기준(LOO)은 그대로 두고,
**지금 열려 있는 질문이 무엇인가**로 골랐다. E11(크기 명시 입력)에서
대조군과 구분이 안 돼 "이 설계로는 아무것도 구분되지 않았다" 로 끝난 전례가 있다.
같은 실수를 반복하지 않으려면 셔플이 필요하다.


### E20 국소 밀도 입력 채널 — 기각. 단 단독 성능은 올랐다 (17차)

옆 워크스트림이 찾은 **학습 없는 국소 밀도**(kxk 창 안 불량 다이 비율)를 입력 채널로 직접 줬다.
one-hot 3채널 -> 5채널(k=5, k=7 추가). 나머지는 `cls_e17.yaml` 과 동일하고
대조군은 `e17_translate_s0~s3` 4 seed 를 재학습 없이 썼다. 반증 조건은 실행 전에
[candidate/local_density_channels.md](../experiments/candidate/local_density_channels.md) 에 박았다.

| | 단독 평균 | 범위 | 앙상블 | LOO 군 평균 |
|---|---:|---:|---:|---:|
| 대조군 translate (4 seed) | 0.7645 | 0.0067 | **0.7755** (4개) | -0.0001 |
| **밀도 k=5,7 (3 seed)** | **0.7712** | 0.0015 | 0.7763 (N개) | **+0.0010** |
| 셔플 대조군 (1 seed) | 0.7611 | — | — | -0.0031 |

**config diff 를 실제로 확인했다.** 저장된 `*_train.json` 을 대조군과 키 단위로 비교하니
다른 것이 `density_ks`, `tag`, `seed` **뿐**이다. 사전 등록한 대로다. 교란이 없다.

**밀도 모델의 단독 최저가 대조군 최고를 넘는다** — 두 분포가 겹치지 않는다.
잡음 기준선 0.0495 와 무관하게, 대조군 자체 범위가 0.0067 인데 그것을 벗어난다.

**그런데 앙상블은 같은 자리다.** 사전 등록한 기각 조건(LOO < +0.003)에 걸린다. **기각.**

seed 범위 **0.0015** 는 이 프로젝트에서 관측된 것 중 가장 좁다(기준선 0.0495 의 1/33,
translate 0.0067 의 1/4). 같은 사이클의
[진단 2](#2-분산-감소가-왜-성능으로-안-이어지는가--설명이-붙었다)가
**"분산 감소는 성능 향상의 전조가 아니다"** 라고 했는데, E20 이 그것의 새 사례다 —
**분산이 33배 좁아졌는데 앙상블은 안 올랐다.**

#### 실행 전에 적은 가설이 둘 다 반증됐다

**A: 경계를 고친다.** none 누출이 1135 로 대조군 범위(875~1,527) 안이고,
클래스별 F1 이 아홉 개 전부 대조군 seed 범위 안이다. **Scratch, Edge-Loc 이 오른다는
예측이 틀렸다.**

**B: 표현 다양성을 하나 더 만든다.** LOO 가 0 이다.

남는 것은 셋째이고, 그것은 **직접 쟀다.**

| 짝 | 예측 불일치 | **오류 상관** |
|---|---:|---:|
| translate 끼리 | 0.0130 | **0.7955** |
| **밀도 끼리** | 0.0086 | **0.8626** |
| translate 대 밀도 | 0.0107 | 0.8311 |

> **C: 밀도 채널은 입력의 결정론적 함수다. seed 가 달라도 모든 모델이 똑같은 추가
> 특징을 계산하므로, 개별 바닥은 올라가는데 서로 상관은 오히려 커진다.**

**밀도 모델끼리가 translate 끼리보다 더 닮았다**(오류 상관 0.8626 대 0.7955).
좋아진 만큼 중복되어 앙상블에서 상쇄된다. 재현: `src/diag_member_diversity.py`.

**이 비교에는 교란이 없다.** 오류 상관은 오류 개수와 얽히기 쉬운데(오류가 적으면
같은 어려운 웨이퍼에 몰려 상관이 커진다), 두 군의 오류 개수가 비슷하다 —
translate 3,266~3,590, 밀도 3,379/3,409. **오류율을 맞춘 상태에서 밀도 쪽이 더 닮았다.**
(반대로 **군 사이** 상관은 오류율에 교란된다. 극좌표가 다른 모든 군과 0.13~0.18 로
가장 낮게 나오는데, 그건 다양해서가 아니라 27,038장을 오검출해 오류 집합 자체가 달라서다.)

이것이 이 프로젝트가 반복해 만난 구조와 같다. **통한 것 다섯 중 셋이 평균내기**이고
(앙상블 = 실행 평균, TTA = 변환 평균, EMA = 시점 평균) "TTA 는 앙상블의 대체재" 였다.
**밀도 채널은 평균내기가 아닌 첫 개선인데, 그것마저 앙상블이 흡수한다.**

#### 맞은 예측도 하나 있다 — 극좌표 실패 모드는 없다

크기 5분위별 none 오검출률이 대조군과 똑같이 평평하다(Q1/Q5 = 0.4배).
극좌표(E15b)는 여기서 0.4~0.5 로 무너졌다. **밀도는 비율이라 크기에 불변**이라는
설계 근거가 실측으로 확인됐다.

#### 셔플 대조군이 답한 것 — 이득은 정보 때문이다

밀도 채널을 **다른 웨이퍼에서 가져온** 대조군을 1 seed 돌렸다.
채널 수, 파라미터, 채널별 통계가 전부 같고 one-hot 과의 대응만 깨진다.

| | 단독 | none 누출 | LOO |
|---|---:|---:|---:|
| 대조군 translate (3채널, 4 seed) | 0.7645 (범위 0.7607~0.7674) | 1,190 (875~1,527) | -0.0000 |
| **셔플 (5채널, 정보 없음, 1 seed)** | **0.7611** | 1,032 | **-0.0031** |
| **밀도 (5채널, 정보 있음, 3 seed)** | **0.7712** (0.7706~0.7721) | 1,135 | **+0.0010** |

**셔플은 단독도 누출도 대조군 범위 안이다.** 즉 **채널을 둘 더 붙이는 것 자체로는
아무 일도 일어나지 않는다.** 반면 밀도는 대조군 범위 **밖**이다.

**차이 +0.0101 이 밀도의 seed 범위(0.0015)의 7배다. 이득은 용량이 아니라 정보다.**

이것이 E11(크기 명시 입력)이 못 한 일이다 — 거기서는 셔플 대조군과의 차이가 0.007 뿐이라
"이 설계로는 아무것도 구분되지 않았다" 로 끝났다. **이번엔 갈렸다.**

**앙상블 기여에서도 셔플이 꼴찌다**(-0.0031, 풀 8개 중 최하). 사전 등록한 채택 조건은
"LOO >= +0.005 **이고** 셔플보다 높을 것" 이었다. **뒷 조건은 만족하고 앞 조건이 안 된다.**
그래서 기각이지만, **기각의 뜻이 "밀도 정보가 쓸모없다" 는 아니다.**
단독에서는 확실히 쓸모가 있고, 앙상블이 그것을 흡수할 뿐이다.

**셔플도 다양성을 못 만든다** — 밀도와의 오류 상관이 0.8608 로 밀도끼리(0.8622)와 거의 같다.
채널이 정보를 담든 안 담든, **결정론적 채널을 붙이면 구성원이 서로 닮아진다.**

#### 평균을 더할수록 이득이 사라진다 — C 의 세 번째 확인

밀도의 우위가 **평균내기를 얼마나 겹치느냐에 따라 단조롭게 줄어든다.**

| 무엇을 평균했나 | 대조군 translate | 밀도 k=5,7 | **차이** |
|---|---:|---:|---:|
| 아무것도 (단독) | 0.7645 (4 seed) | **0.7712** (3 seed) | **+0.0067** |
| + TTA (변환 평균, 8배) | 0.7712 (4개 평균) | 0.7751 (3개 평균) | **+0.0039** |
| + 앙상블 (실행 평균) | 0.7755 (4개) | 0.7763 (3개) | **+0.0008** |

**우위가 +0.0067 -> +0.0039 -> +0.0008 로 반씩 줄어든다.**
평균내기(TTA 든 앙상블이든)가 밀도 채널이 해 준 일을 이미 하고 있다는 뜻이고,
가설 C 를 다양성 측정과 독립적으로 한 번 더 확인한다.

덤으로 **TTA 이득이 모델이 강할수록 작다는 기존 관측도 다시 맞는다** —
밀도 +0.0040, translate +0.0067, resnet18 계열 +0.0129, 다른 백본 +0.0289.

#### 남는 것 — 단일 모델 최고 기록

**0.7721 는 TTA 없는 단일 모델 최고다**(이전 0.7674, 3 seed 평균 0.7712).
**단 TTA 를 걸면 0.7768 로 기존 최고 0.7769(translate+TTA)와 구분되지 않는다.**
사전 등록한 판정 기준이 아니므로
"채택" 이라 쓰지 않는다. 다만 **추론을 한 번밖에 못 하는 상황에서는 지금까지 중 최선의 구성**이고,
그 축을 볼 거라면 다음 사이클에 따로 사전 등록해야 한다.

#### 전체 최고 기록은 안 바뀐다 — 대조군이 잡았다

현재 최고 풀(TTA 18개, 0.7931)에 밀도 모델을 넣으면 **0.7953** 이 나온다.
새 기록처럼 보인다. **그런데 대조군을 세우면 사라진다.**

| 풀 | macro-F1 | none 누출 |
|---|---:|---:|
| TTA 18개 (기준) | 0.7931 | 1,057 |
| **+ 밀도 2개(비-TTA)** | **0.7953** | 1,022 |
| + translate 2개(비-TTA), 6가지 조합 | **0.7929 ~ 0.7948** | 1,004 ~ 1,048 |
| + translate 4개 전부(비-TTA) | 0.7929 | 1,007 |

**같은 개수의 비-TTA translate 를 넣어도 0.7929~0.7948 이 나온다.**
밀도의 0.7953 은 그 범위 바로 위(+0.0005)다. **이득의 거의 전부가
"비-TTA 구성원을 둘 더 넣은 것" 이고 밀도 채널 때문이 아니다.**

덤으로 **풀 구성 잡음의 폭을 처음으로 직접 쟀다 — 약 ±0.002** 다.
구성원 둘을 무엇으로 고르느냐에 따라 0.7929~0.7953 을 오간다.
이것이 "0.7921~0.7931 을 0.793 으로 읽는다" 를 사후에 정당화한다.
**최고 기록은 0.793 그대로다.**

#### 누출 법칙의 새 데이터점 — 맞는다

같은 사이클의 [진단 2](#2-분산-감소가-왜-성능으로-안-이어지는가--설명이-붙었다)가
"성능은 none 누출의 **수준**이 정한다"(spearman -0.915)고 했다.
E20 이 그 법칙의 새 데이터점이고 **어긋나지 않는다.**

| | 단독 평균 | none 누출 평균 |
|---|---:|---:|
| 대조군 translate (4 seed) | 0.7645 | 1,190 |
| 밀도 (3 seed) | **0.7712** | **1135** |

**부호는 맞는다** — 누출이 줄었고 macro 가 올랐다.
**다만 크기는 안 맞는다.** translate 는 누출을 1,772 줄여 +0.0384 를 얻었는데
(100 당 약 +0.0022), 밀도는 누출을 55 줄이고 +0.0067 을 얻었다.
누출 감소만으로는 예상되는 +0.0012 의 다섯 배다.
**그러므로 밀도의 단독 이득을 누출 감소로 다 설명할 수 없다.** 나머지가 무엇인지는 모른다.
(누출 법칙은 군 수준 상관 r=-0.91 이지 정확한 기울기가 아니다. 그 한계 안에서 읽어야 한다.)

앙상블에서 안 오르는 것은 누출 법칙과 별개의 이야기다 — 다양성 쪽이다.
