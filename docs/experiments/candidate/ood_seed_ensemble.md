# seed 앙상블 — 초기화 잡음을 평균으로 지운다, 착수 전 사전등록

작성 2026-08-23 22:30, 브랜치 `exp/ood-oneclass`. **한 줄도 실행하기 전에 쓴다.**
판정은 §8 에 append 한다.

## 1. 오늘 하루의 지배적 발견이 이 arm 을 만든다

17차, 20차, 21차가 전부 같은 벽에 부딪혔다 — **초기화 잡음이 효과보다 크다.**

| 사이클 | 이득 | seed 폭 |
|---|---:|---:|
| 17차 O2 | 부호가 갈림 | **0.224** |
| 21차 fuse4 | **+0.0001** | **0.0145** |

**21차에서 세 seed 의 fuse4 가 0.8238 / 0.8292 / 0.8383 이었다.**
하나를 고르면 그건 test 로 고르는 것이고, 평균을 보면 이득이 0 이다.
**그런데 셋을 다 쓰면 초기화 잡음 자체가 줄어든다.**

## 2. 왜 이것이 튜닝이 아닌가

- **seed 집합을 `{0, 1, 2}` 로 못 박는다.** 이건 17차에서 **결과를 보기 전에** 정한 집합이고
  그 뒤로 한 번도 안 바꿨다. **성능을 보고 seed 를 고르거나 늘리지 않는다.**
- **결합 규칙을 하나만 정한다**(§3). 여러 앙상블 방식을 재서 고르지 않는다.
- **전부 범위 A** — 정상 웨이퍼만 쓴다.
- **`epoch=3` 은 `test_dev` 에서 고른 값이다**(정정 16). 21차와 같은 튜닝이고
  같은 이유로 **봉인이 최종 확인**이다.

## 3. arm — 결합 규칙을 실행 전에 하나로 정한다

seed `s` 마다 O2 kNN 점수 `t_s`(train-none)와 `d_s`(test_dev)를 얻고,

```
u_s   = ecdf_percentile(t_s, d_s)          # 참조는 그 seed 의 train-none
u_ens = (u_0 + u_1 + u_2) / 3              # 백분위의 평균. 점수의 평균이 아니다
fuse5 = Fisher(u_A, u_B, u_C, u_ens)
```

**백분위를 평균하는 이유**: seed 마다 kNN 거리의 척도가 다르다(17차 실측: 평균 0.0021~0.0884).
**점수를 그냥 평균하면 척도가 큰 seed 가 지배한다.** 백분위는 seed 마다 [0,1] 로 정규화된다.

| arm | 무엇 |
|---|---|
| **fuse5 (주)** | 위 식 |
| fuse3 (대조) | 채택 arm. `test_dev` **0.8304** |
| (참고) fuse4 s0/s1/s2 | 21차의 개별 seed. **0.8238 / 0.8292 / 0.8383** |
| (참고) O2 앙상블 단독 | `u_ens` 만 |

## 4. seed 변동을 어떻게 다루는가 — 이 arm 은 단일 값이다

**앙상블은 seed 집합이 고정되면 결정론적이다.** 그러므로 "3 seed 최소값" 규칙을 못 쓴다.
대신 이렇게 한다.

1. **짝지은 부트스트랩 CI** 로 fuse3 와 비교한다(웨이퍼 재표본).
2. **개별 seed 최악값(0.8238)보다 나은 것은 당연하므로 그것을 성과로 적지 않는다.**
   비교 대상은 **fuse3** 하나다.
3. **다른 seed 집합이면 다른 앙상블이 된다.** 그 변동은 못 잰다 —
   재려면 seed 를 더 뽑아야 하고 그건 이 사이클 밖이다. **못 잰다고 적는다.**

## 5. 반증 조건

1. **fuse3 대비 짝지은 blocked AUPR 차이 CI 하한이 0 이하면 기각.**
2. **이득이 21차의 seed 폭(0.0145)보다 작으면, 이겨도 "잡음 안" 이라고 적는다.**
   즉 **CI 하한이 0 을 넘고 동시에 이득이 0.0145 를 넘어야** 실질적 채택 후보다.
3. **Scratch, Center, Loc 중 하나라도 CI 가 겹치지 않게 내려가면 기각.**
4. **고유값 1,000 미만이면 채택 보류.**
5. **dieSize `562-776` 또는 `1090-1334` 에서 fuse3 보다 나빠지면 기각.**
   (21차에서 fuse4 가 `562-776` 에서 세 seed 다 나빠졌다. **앙상블이 그걸 고치는지가 핵심이다.**)
6. **one-class 위반이면 무효.** `select_train_none` 을 거친다.
7. **1~6 을 전부 통과하면, 그때 `test_sealed` 를 딱 한 번 연다.** 아니면 안 연다.

## 6. 실행 전 예측

1. **fuse5 가 fuse3 를 이긴다**(CI 하한 > 0). 세 seed 중 둘이 지거나 비겼지만
   **평균화가 각 seed 의 잡음을 지우므로 최선(0.8383)에 가까워질 것**이다.
2. **그러나 이득이 0.0145 를 못 넘는다** → **반증 조건 2 에 걸려 "잡음 안" 으로 적힌다.**
   근거: 세 seed 평균이 0.8304 로 fuse3 와 정확히 같다. 앙상블이 평균 이상을 주려면
   **seed 간 오차가 서로 상쇄돼야 하는데**, 셋은 같은 과제·같은 자료로 학습해
   **오차가 공통일 가능성이 크다.**
3. **`562-776` 은 여전히 fuse3 보다 나쁘다** — 세 seed 가 다 나빴던 것은
   초기화 잡음이 아니라 **그 구간의 체계적 문제**이기 때문이다. → **반증 조건 5 발동.**
4. **FPR@95TPR 은 fuse3 보다 낫다**(세 seed 다 나았다).
5. **고유값은 8만 이상**이다.

**예측 2 와 3 이 맞으면 이 사이클도 기각이고, 결론은
"앙상블이 초기화 잡음은 줄이지만 체계적 약점은 못 고친다" 이다.**
그건 **오늘 세 사이클이 부딪힌 벽의 정체를 정확히 하는 것**이라 값어치가 있다.

## 7. 못 하는 것

- **다른 seed 집합의 변동을 못 잰다**(§4-3).
- **`epoch=3` 이 최적인지 모른다** — 격자가 `{0,1,3,6,12}` 뿐이었다.
- **seed 를 더 늘리면 어떻게 되는지 안 잰다.** 3 으로 못 박았다.
