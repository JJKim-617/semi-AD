# 후보 — 여덟 사이클 동안 test 를 보고 고른 것이 얼마나 위험한가

**반증 조건은 실행 전에 적는다.** 판정은 아래 별도 절에 append 한다.
작성 2026-08-23 03:2x KST (실행 전).

## 무엇을 묻는가 — 나 자신을 의심한다

이 워크스트림의 **구조적 약점**을 아직 안 쟀다.

**val 은 못 쓴다**(품질을 못 재고 파국만 감지한다 — 기획서 §1). 그래서 여덟 사이클 내내
**공식 test 에서 재고, 그 수치를 보고 다음 사이클의 방향을 정했다.**
반증 조건을 실행 전에 박고 주 arm 을 하나로 고정하는 규율은 지켰지만,
**"어떤 축을 다음에 팔지" 는 매번 test 결과를 보고 정했다.**

**즉 arm 하나하나는 사전등록했어도, 사다리 전체의 경로는 test 에 적합됐다.**
100개가 넘는 arm 을 재고 그중 최고를 보고하고 있으므로 **최고 arm 의 test 수치는
낙관적으로 편향돼 있다.** 얼마나인지 모른 채로 끝낼 수는 없다.

## 무엇을 재는가

공식 test 118,595장을 **lot 단위로 두 반쪽**으로 가른다(lot 이름 해시, 결정론적).
lot 단위여야 같은 lot 의 거의 같은 웨이퍼가 양쪽에 갈리지 않는다 —
`docs/specs/splits.md` 가 val 을 lot 단위로 뗀 것과 같은 이유다.

각 arm 을 **반쪽 1, 반쪽 2, 전체**에서 각각 blocked AUPR 로 잰다.
**어떤 것도 다시 적합하지 않는다** — 보정 참조는 train-none 그대로다.
바뀌는 것은 평가 집합뿐이다.

측정할 arm: 채택된 계보 전부 + **기각한 것 두 개**
(T-RESIZE S_nll, 가드 없는 선 필터 L=7). 기각도 반쪽에서 유지되는지 본다.

## 반증 조건 (실행 전 확정)

1. **두 반쪽에서 최고 arm 이 다르면, "현재 최선" 을 한 arm 으로 지목할 수 없다.**
   그때는 최상위 몇 개를 동률로 보고한다.
2. **최고 arm 의 반쪽 간 차이(|h1 - h2|)가 2위와의 격차보다 크면,
   그 순위는 잡음 안이다.** 그렇게 적는다.
3. **arm 순위의 두 반쪽 간 Spearman 상관이 0.9 미만이면 순위 자체가 불안정하다.**
4. **바닥 대비 이득(0.3854 → 0.8325)이 반쪽 간 변동의 5배 미만이면,
   전체 주장까지 흔들린다.** 5배 이상이면 **큰 주장은 안전하고 미세 순위만 위험**하다고 적는다.
5. **기각한 arm 이 어느 반쪽에서든 채택 arm 을 넘으면 그 기각을 재검토한다.**

## 실행 전 예측

- **큰 주장은 안전할 것이다.** 바닥 대비 +0.45 는 반쪽 변동(짐작 ±0.02)보다 훨씬 크다.
- **최상위 두세 개(fuse3, A+B, B+C)의 순서는 뒤집힐 수 있다.** 격차가 0.02~0.03 이다.
- **기각한 것들은 반쪽에서도 확실히 진다.** 격차가 0.4~0.7 이라 뒤집힐 여지가 없다.
- **Spearman 은 0.95 이상**일 것이다.

## 이것으로 해결되지 않는 것 — 미리 적는다

**반쪽 검사는 선택 편향을 없애지 못한다.** 두 반쪽 다 내가 이미 본 test 에서 나온다.
**진짜 해결은 한 번도 안 본 자료**(다른 fab, 다른 기간, 또는 lot 을 미리 떼어 봉인한 홀드아웃)뿐이다.
이 사이클이 주는 것은 **"변동의 크기가 이득에 비해 얼마나 되는가" 라는 하한선**이지
편향의 제거가 아니다. 그렇게만 주장한다.

### 한 줄

**큰 주장은 안전하고, 미세 순위도 이번엔 안 흔들렸다.**
바닥 대비 이득이 반쪽 변동의 **12.5배**이고, 두 반쪽의 arm 순위 Spearman 이 **1.0000** 이다.
**다만 이것이 선택 편향을 없앤 것은 아니다** — 아래 한계 절.

### 반증 조건별 판정

**1. 두 반쪽의 최고 arm 이 같은가 → 같다.** 양쪽 다 `fuse3`.

**2. 최고 arm 의 반쪽 차이(0.0094)가 1위-2위 격차(0.0190)보다 작은가 → 작다.**
**순위가 잡음 안이 아니다.** (2위는 탐색 arm `B+C` 다.)

**3. 순위 Spearman → 1.0000.** 여덟 개 arm 의 순서가 두 반쪽에서 완전히 같다.

**4. 바닥 대비 이득 0.4471, 최대 반쪽 변동 0.0357 → 배수 12.5.**
기준(5배)을 넉넉히 넘는다. **"바닥 0.3854 에서 0.8325 로 올렸다" 는 주장은 안전하다.**

**5. 기각한 arm 이 채택 arm 을 넘는 경우 → 없다.**
채택 arm 의 반쪽 최저가 0.6938 인데 기각 arm 최고가 0.3763 이다.
**여덟 사이클의 기각 판정들이 반쪽에서도 유지된다.**

## 이것으로 해결되지 않는 것 — 실행 전에 적어 둔 그대로

**반쪽 검사는 선택 편향을 없애지 못한다.** 두 반쪽 다 **내가 이미 여덟 사이클 동안 본**
test 에서 나온다. 100개가 넘는 arm 을 재고 그중 최고를 보고하고 있으므로
**최고 arm 의 test 수치는 여전히 낙관적으로 편향돼 있다.**

이 사이클이 준 것은 딱 하나다: **평가 집합을 절반으로 바꿔도 순서와 크기가 유지된다**는 것.
그건 **"우연히 이 118,595장에만 맞는 arm 을 골랐다" 는 가설을 약화**시키지만
**"test 전체에 조금씩 과적합됐다" 는 가설은 못 건드린다.**

**진짜로 필요한 것은 한 번도 안 본 자료다** — 다른 fab, 다른 기간,
또는 **처음부터 lot 을 떼어 봉인한 홀드아웃**.
이 워크스트림은 그걸 안 만들고 시작했다. **다음 워크스트림은 그것부터 만들어야 한다.**

## 설명 없는 관측

- **왜 반쪽 변동이 arm 마다 다른가.** 약한 arm 일수록 크다(원 바닥 0.0357,
  최선 0.0094). 점수 분포가 넓을수록 안정적인 것 같은데 확인하지 않았다.
- 반쪽2 가 거의 모든 arm 에서 반쪽1 보다 높다. 결함비율이 조금 높아서(0.0674 대 0.0658)
  AUPR 바닥이 높은 것으로 설명될 수 있으나 **분해해 확인하지 않았다.**
