# 가설 — BN 통계를 타겟 분포로 다시 재는 것만으로 분포 이동을 줄인다

제안일 2026-08-22. 상태: 실험 예정.

## 문제

학습으로 좁힐 수 있는 격차는 거의 다 좁혔다. val 0.95 대 test 0.75 로 남은 0.2 는
전부 분포 이동이다. 지금까지 시도한 것은 전부 "같은 모델을 어떻게 학습시킬까" 였고,
타겟 분포 자체를 모델에 알려준 적이 없다.

## 가설

BatchNorm 의 running mean 과 variance 는 **학습 분포의 통계**다. 추론 시 이 값을
그대로 쓰는데, 타겟 분포가 다르면 각 층의 정규화가 어긋난다.

라벨 없는 test 118,595장으로 이 통계만 다시 재면 정규화가 타겟에 맞춰진다.
**가중치는 건드리지 않는다. 라벨도 쓰지 않는다.**

이것은 사후 오프셋 튜닝과 성격이 다르다. 오프셋은 마지막 결정 경계만 옮기지만
BN 재추정은 **모든 층의 표현**을 타겟 통계에 맞춘다.

## 검증 설계

기준선은 E8(pad, 0.7485). 가중치 고정, BN 통계만 교체한다.

| 태그 | 조건 | 답하는 질문 |
|---|---|---|
| `bn_test` | test 전체로 BN 재추정 | 타겟 통계가 도움이 되는가 |
| `bn_val` | val 로 재추정 | **대조군.** val 은 학습 분포라 이득이 없어야 한다 |
| `bn_mix` | 학습 통계와 타겟 통계를 섞음(momentum 조절) | 전부 바꾸는 것이 최선인가 |

## 기각 조건

- `bn_test` 가 기준선을 못 넘으면 BN 통계는 이 격차의 원인이 아니다.
- `bn_val` 이 `bn_test` 만큼 오르면 개선의 원인이 타겟 적응이 아니라
  단순한 통계 재추정(예: 배치 크기 효과)이다. 이 대조군이 핵심이다.

## 주의

test 로 BN 을 재추정하는 것은 transductive 설정이다. 라벨은 쓰지 않지만
테스트 데이터 전체를 한 번에 본다는 가정이 필요하다. 실제 팹에서 웨이퍼가
배치로 들어오는 상황이면 타당하고, 한 장씩 실시간 판정해야 하면 성립하지 않는다.
결과를 보고할 때 이 가정을 명시한다.
