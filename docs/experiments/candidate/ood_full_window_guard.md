## 이 실험이 생긴 경위 — 밝혀 둔다

3차 사이클에서 방향성 선형 필터를 **포화 때문에** 기각했다.
그때 원인을 **"정상 웨이퍼의 바깥 링에 연속으로 죽은 다이가 줄줄이 있다"** 로 적고
그것을 `docs/reports/OOD.md` 에 "알아낸 사실" 로 올렸다.

**그 설명이 틀렸다.** 옆 워크스트림(`Semi-AD`)이 같은 필터를 이식하면서
포화 창의 다이 개수를 세어 봤고 최빈값이 3이었다고 기록했다.
**내 worktree 에서 직접 확인했다**(표본 8,000장, 정상 포화 70.63%):

| 포화 창의 다이 개수 | 비중 |
|---:|---:|
| 3개 | **43.1%** |
| 4개 | 30.1% |
| 2개 | 17.2% |
| 1개 | 6.0% |
| **7개 (온전)** | **0.2%** |

**온전한 창만 세면 정상 포화가 70.63% → 0.15% 다.**

즉 포화는 가장자리에 진짜 긴 불량 줄이 있어서가 아니라,
**창이 웨이퍼 경계에서 잘려 분모가 2~4로 무너지기 때문**이다.
2~4개 연속 불량은 불량률 11.6% 에서 우연히 늘 생긴다.

내가 "우연이 아니다" 라고 쓴 근거였던 `8 x 800 x 0.116^7 = 0.002` 계산도
**창에 다이가 7개 있다고 가정**한 것이라 무효다. 다이가 3개면 0.116³ ≈ 0.0016 이고
창 수를 곱하면 흔한 일이 된다.

**그러므로 3차 사이클의 기각 판정은 유지되지만, 기각 사유로 적은 기작은 정정한다.**
그리고 원인이 분모 붕괴라면 **분모를 보장하면 필터가 되살아나야 한다.**

## 주 arm

**`line7_full`** — 길이 7, 폭 1, 8방향, **창 안 다이가 7개인 곳에서만 점수를 낸다**
(`min_dies=length`). 3차 사이클의 주 arm 과 **가드 하나만 다르다.**
같은 조건에서 가드의 효과만 보려는 것이다.

## 같이 재는 것 (사전등록)

1. **길이 훑기** L = 5, 7, 9, 11, 13, 15 (가드 있음/없음 짝). 판정은 **L 다수결**.
2. **정사각 창에도 같은 가드** — `die` 정규화 정사각 k=7 은 가장자리에서 같은 분모 붕괴를 겪는다.
   가드가 거기서도 통하면 이건 선 필터 얘기가 아니라 **창 통계 일반의 얘기**다.
3. **현재 최선(k² 5x5 + 반경보정)과의 융합** — 선 필터와 정사각 창은 서로 다른 결함을
   본다고 예상하므로(Scratch 대 Edge), 섞으면 오를 수 있다.
   융합 보정은 **train none 만** 쓴다.

## 대조군

- 3차 사이클의 가드 없는 선 필터 (blocked AUPR 은 이번에 다시 잰다)
- **현재 최선**: k² 5x5 + 반경 대역 보정, blocked AUPR **0.7646**, FPR@95TPR 0.3226
- 클래스별 기준: Scratch **0.8471**(k² 5x5), Center **0.9612**(k² 3x3), Loc **0.9795**(k² 5x5)

## 반증 조건 (실행 전 확정)

1. **가드가 L 의 과반에서 blocked AUPR 을 올리지 못하면, 가드는 설계 축이 아니다.**
   짝지은 blocked 검정 p < 0.01.
2. **주 arm(또는 어떤 길이의 온전창 선 필터)이 Scratch 0.8471 을 CI 를 넘겨
   개선하지 못하면, "선 창이 긁힘을 잡는다" 를 다시 기각한다.**
   3차에서 이미 한 번 기각한 주장이므로 이번에도 못 넘으면 그걸로 닫는다.
3. **전체 blocked AUPR 이 0.7646 을 못 넘으면 "새 최선" 이라고 부르지 않는다.**
   Scratch 만 올라도 그건 **부분 채택**이고, 그렇게 적는다.
4. **융합이 현재 최선을 못 넘으면 선 필터는 하류로만 넘긴다**(8종 분류용 특징).
5. **고유값 개수와 운영 지점 50/80/95% 를 반드시 낸다.**
   가드는 점수를 낼 수 있는 다이를 줄이므로 **고유값이 더 적어질 수 있다.**
6. **dieSize 구간별로 낸다.** 가드는 **작은 웨이퍼를 더 많이 버린다** —
   작은 웨이퍼일수록 온전 창을 만들 여지가 적다. 562~1090 에서 무너지면 기각.
7. **가드 때문에 점수를 아예 못 내는 웨이퍼가 몇 장인지 보고한다.**
   온전 창이 하나도 없는 웨이퍼는 점수가 0 이 되어 **조직적으로 정상 취급**된다.
   그 수가 크면 그것만으로 지표가 왜곡된다.

## 실행 전 예측

- **가드가 포화를 없앤다** (이미 확인: 70.63% → 0.15%).
- **Scratch 가 크게 오른다.** 선 창이 원래 노린 것이고 이제 분모가 정직하다.
- **작은 웨이퍼가 손해를 본다.** 조건 6, 7 이 그것을 잡으라고 있다.
- **정사각 창에도 가드가 통한다.** 분모 붕괴는 창 모양과 무관한 문제다.
- **전체 AUPR 은 현재 최선을 못 넘을 수 있다.** 선 필터는 Edge 계열에 약하고
  Edge 가 결함의 49.4% 다.

### 반증 조건별 판정

**1. 가드가 L 의 과반에서 이기는가 → 5/5. 통과.**

| L | 가드 | 없음 | 짝지은 차이(blocked) | p |
|---|---:|---:|---:|---:|
| 5 | 0.2270 | 0.0696 | [+0.1535, +0.1612] | 0.0000 |
| 7 | 0.4826 | 0.0891 | [+0.3847, +0.4014] | 0.0000 |
| 9 | 0.6361 | 0.1039 | [+0.5226, +0.5415] | 0.0000 |
| 11 | 0.6562 | 0.1052 | [+0.5421, +0.5605] | 0.0000 |
| 15 | 0.6005 | 0.1012 | [+0.4907, +0.5083] | 0.0000 |

**그러나 정사각 창에서는 가드가 해롭다**: 0.7098 → 0.6239, **[-0.0950, -0.0764], p=0.0000**.
**내 예측("분모 붕괴는 창 모양과 무관하니 정사각에도 통한다")이 틀렸다.**
선 창은 길이 7 중 3칸만 남는 식으로 **심하게** 잘리지만,
정사각 7x7 은 가장자리에서도 20칸 안팎이 남아 분모가 그렇게까지 안 무너진다.
거기서 온전 창(49칸)을 요구하면 **가장자리 정보를 통째로 버리는 손해**가 더 크다.
**가드는 창 모양에 따라 부호가 바뀐다.**

**2. Scratch 가 0.8471 을 넘는가 → 크게 넘는다. 3차의 기각을 뒤집는다.**

| arm | Scratch AUROC |
|---|---|
| E0 불량 다이 개수 (원래 바닥) | 0.6559 |
| 3차 line7 가드없음 | 0.6332 |
| 5차 최선 (k² 5x5 + 반경보정) | 0.8409 [0.8269, 0.8526] |
| line9 온전창 (단독) | 0.9339 [0.9245, 0.9432] |

**"선 창이 가는 긁힘을 잡는다" 는 주장은 참이었다.** 3차에서 기각한 것은
주장이 틀려서가 아니라 **분모가 망가진 구현으로 쟀기 때문**이다.

**3. 전체 blocked AUPR 이 0.7646 을 넘는가 → 융합만 넘는다.**
단독 선 필터는 최고가 0.6562 로 **전부 진다**(line11 [-0.1202, -0.0995], p=0.0000).
융합은 이긴다: **최선+line11 [+0.0357, +0.0462]**, 최선+line7 [+0.0071, +0.0188], 둘 다 p=0.0000.

**4. 융합이 현재 최선을 넘는가 → 넘는다.** 선 필터는 하류 전용이 아니라 **탐지에 직접 기여한다.**

**5. 고유값과 운영 지점 → 단독 선 필터는 못 쓴다, 융합은 쓸 만하다.**
`line11 온전창` 은 고유값이 **11개**뿐이다. 융합은 1,410개다.

| arm | 50% | 80% | 95% |
|---|---|---|---|
| E0 불량 다이 비율 (원래 바닥) | 0.247 / 12,024 | 0.121 / 46,016 | 0.084 / 81,522 |
| 정사각 die k=7 | 0.861 / 639 | 0.355 / 11,465 | 0.122 / 53,729 |
| 5차 최선 | 0.895 / 465 | 0.539 / 5,394 | 0.174 / 35,709 |
| **융합 최선+line11 온전창** | **0.932 / 287** | **0.628 / 3,734** | 0.210 / 28,245 |
| 융합 최선+line7 온전창 | 0.886 / 510 | 0.598 / 4,245 | **0.276 / 19,666** |

**80% 재현율에서 헛경보 46,016 → 3,734장(12배 감소), precision 0.121 → 0.628.**
95% 에서는 line7 융합이 **19,666장**으로 가장 낫다 — **두 융합이 운영 지점마다 갈린다.**

**6. dieSize 구간 → 전 구간 개선, 붕괴 없다.**
562-776 0.7348 → 0.7950, 776-1090 0.8401 → 0.8651, >1600 0.4798 → 0.5468.

**7. 가드가 웨이퍼를 통째로 침묵시키는가 → 거의 없다.**
점수가 0 이 되는 웨이퍼가 L=5 에서 3장, L=7~15 에서 4장이고 **그중 결함은 0장**이다.
118,595장 중 4장이라 지표에 영향이 없다.

## 설명 없는 관측

- **왜 L=11 이 최적인가.** 9 < 11 > 15 로 봉우리가 있다. 긁힘 길이 분포와 관련 있을 것 같지만
  확인하지 않았다.
- **두 융합이 운영 지점마다 갈리는 이유.** line11 융합이 50%, 80% 에서 낫고
  line7 융합이 95% 에서 낫다(19,666 대 28,245). 이유를 모른다.
- **정사각 창에서 가드가 해로운 정확한 손익분기.** 창 크기와 가드 문턱의 관계를 훑지 않았다.
