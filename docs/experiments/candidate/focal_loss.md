# 가설 — focal loss 로 불균형과 불안정을 함께 다룬다

제안일 2026-08-21. 상태: 실험 진행 중.

## 문제

E4, E4b 에서 역빈도 class weight 가 test macro-F1 을 올렸지만(+0.10) 학습을 불안정하게 만들었다.
E4 는 ep4 에 accuracy 0.180, E4b 는 0.143 까지 붕괴했다 회복했다.
원인 가설은 극소수 클래스(Near-full 학습셋 기준 소수)에 걸린 큰 고정 배율이 gradient 분산을 키운다는 것이다.

## 가설

focal loss 는 같은 불균형 문제를 다루되 부작용이 작다.

| | 역빈도 class weight | focal loss |
|---|---|---|
| 조절 단위 | 클래스 전체에 고정 배율 | 샘플별 난이도 |
| 크기 | 빈도의 역수라 무제한 | `(1-p)^gamma` 로 유계 |

test 의 93.3% 가 none 이고 대부분 쉬운 샘플이므로, 눌러야 할 대상이 명확하다.

## 검증 설계

증강은 E3 에서 검증됐으므로 전부 증강 ON 위에서 손실만 바꾼다. 기준선은 E4b 0.6545.

| 태그 | 조건 | 이 실험이 답하는 질문 |
|---|---|---|
| `e5_focal` | focal gamma=2, alpha 없음 | class weight 를 focal 로 **대체**하면 어떤가 |
| `e5_focal_a` | focal + alpha(역빈도) | 두 기법을 겹치면 E4b 를 넘는가 |
| `e5_cw_clip` | E4b + grad clip 1.0 | **불안정이 gradient 분산 탓인지 분리** |

`e5_cw_clip` 이 핵심 대조군이다. focal 이 이기더라도 "손실 함수가 나아서"인지
"단지 안정화돼서"인지 구분해야 한다. clip 만으로 E4b 가 개선되면 원인은 손실 함수가 아니었던 것이다.

## 기각 조건

- focal 단독이 E3(증강만, 0.6350)을 못 넘으면 focal 이 class weight 를 대체하지 못한다는 뜻이다.
- `e5_cw_clip` 이 focal 계열과 비슷하면 문제는 손실 설계가 아니라 최적화 안정성이었다.
