# 상한 재계산과 2단계 분해 판정 (2026-08-23, 학습 없음)

재현: `python3 src/diag_ceilings.py`. 원자료 [evidence/ceilings.json](evidence/ceilings.json).

## 결론 둘

1. **상한이 0.93 에서 0.83 으로 내려갔다.** 이전 값은 10개 앙상블 0.7809 시절 것이다.
   틀렸던 것이 아니라 **모델이 좋아지며 쉬운 오류를 이미 먹었다.**
2. **2단계 분해는 안 된다.** 임계값을 test 라벨로 직접 최적화해도 flat 보다 낮다.

## 상한 (TTA 18개, 현재 최선 0.7931 기준)

| 조건 | **현재** | 이전 판 (0.7809 시절) |
|---|---:|---:|
| none 오검출 전부 제거 | **0.8274** | 0.9271 |
| 결함 recall 전부 1.0 | **0.8409** | 0.8869 |
| **none/결함 이진이 완벽 + 현재 8종 헤드** | **0.8746** | — |
| 현재 이진 + 8종 헤드가 완벽 | **0.8850** | — |

**세 번째 줄이 이 표의 핵심이다.** 경계를 완벽하게 풀어도 0.8746 으로
목표 0.87 을 겨우 넘는다. 한쪽 축만으로는 둘 다 0.87 아래다(0.827, 0.841).

오류 3,233장 중 결함끼리의 혼동은 **647장(20.0%)** 이고,
참 결함만 놓고 8종을 맞히는 정확도는 **0.8699** 다.

## 2단계 분해

`1 - p(none)` 을 stage-1 점수로, 결함 8종 argmax 를 stage-2 로 놓고
임계값 400개를 훑어 **test 라벨로 직접** 최선을 골랐다.

| 구성 | macro-F1 | FP | FN |
|---|---:|---:|---:|
| 현재 flat argmax | **0.7931** | 1,057 | 1,529 |
| 2단계 + 오라클 임계값 (t=0.4807) | **0.7922** | 1,261 | 1,359 |
| 2단계 + 완벽한 이진 | 0.8746 | 0 | 0 |

**오라클로도 flat 보다 0.0009 낮다.** 임계값을 움직이면 FP 와 FN 을 맞바꿀 뿐
총합이 안 준다. **flat 의 암묵적 이진 경계가 이미 최적이다.**

15차에서 "클래스별 오라클 임계값도 +0.006 뿐" 이라며 결정 규칙 축을 닫았는데,
**2단계 프레이밍에서도 같은 결론이 나온다.**

## 함의

2단계는 **결정 규칙을 바꾸는 것으로는 아무것도 못 얻는다.**
stage-1 에 지금보다 나은 **점수**가 있어야만 의미가 있다 — 즉 새 모델이다.
그리고 같은 사이클의 진단 셋
([local_density](../local_density/README.md))은 손으로 만든 신호가
바로 그 경계에서 애매하다고 말한다.

## 성립 범위

- 상한은 **현재 앙상블에 상대적**이다. 모델이 또 좋아지면 또 내려간다.
- "8종 헤드가 완벽" 은 참 결함에만 적용한 것이고, none 을 결함이라 부른 것은 그대로 둔다.
- 오라클 임계값은 test 라벨을 봤다. **실제로 쓸 수 있는 값이 아니라 상한이다.**
