# lot 문맥 — 웨이퍼맵 밖의 정보도 같은 편이다 (2026-08-23, 학습 없음)

재현: `python3 src/diag_lot_context.py`. 원자료 [evidence/lot_context.json](evidence/lot_context.json).

**결론: 같은 lot 의 형제 웨이퍼가 주는 문맥도 앙상블의 경계 오류를 못 고친다.
오히려 모델과 같은 방향을 가리킨다.**

## 왜 봤나

상한 재계산([research/ceilings/](../ceilings/README.md))이 이렇게 말한다 —
**none/결함 이진을 완벽하게 풀어야 0.8746 이고 그래야 목표 0.87 을 겨우 넘는다.**
그런데 웨이퍼맵에서 뽑은 신호(국소 밀도, 선 필터)는 전부 경계 오류 위에서 같은 편이었다.
그러면 **웨이퍼맵 밖**을 봐야 한다.

`splits.md` 대로 **train/val 과 test 는 lot 을 하나도 공유하지 않는다**(실측 재확인).
그래서 train 라벨을 끌어올 수 없다. 대신 **test lot 안에서** 형제 웨이퍼에 대한
**모델 자신의 예측**을 쓴다 — 라벨을 안 보므로 누수가 아니고, 팹에서 웨이퍼가
lot 단위로 들어온다는 점에서 실제로 쓸 수 있다. test lot 당 웨이퍼는 중앙값 **25장**이다.

## lot 안에서 라벨은 실제로 뭉친다 — 다만 약하다

| 점수 (자기 자신 제외) | 이진 AUROC |
|---|---:|
| lot **참** 결함률 (라벨을 봄, 상한) | 0.6904 |
| lot **예측** 점수 평균 (실사용 가능) | 0.6846 |
| (참고) 자기 웨이퍼의 모델 점수 | **0.9807** |

**뭉치기는 한다**(0.69 > 0.5). 그리고 예측 기반(0.6846)이 라벨 기반 상한(0.6904)에
거의 닿는다 — **모델 예측만으로 lot 문맥을 거의 다 뽑아낼 수 있다.**
다만 웨이퍼 자신의 점수(0.9807)에 한참 못 미친다.

## 그런데 경계 오류 위에서는 같은 편이다

| 점수 | FP 대 TN | FN 대 TP | 판정 |
|---|---:|---:|---|
| lot 참 결함률 (상한) | 0.6315 | 0.4289 | **같은 편** |
| lot 예측 점수 평균 | 0.7085 | 0.3748 | **같은 편** |
| (비교) 국소 밀도 k=5 | 0.8806 | 0.2126 | 같은 편 |

고치려면 `FP 대 TN < 0.5` 이고 `FN 대 TP > 0.5` 여야 한다. 둘 다 반대다.

**앙상블이 none 을 결함이라 부른 웨이퍼는 실제로 결함이 많은 lot 에서 나왔고,
놓친 결함은 대체로 깨끗한 lot 에서 나왔다.**

## 이것이 라벨 애매성 쪽 증거를 하나 더 보탠다

오검출 1,057장은 (1) 국소 밀도로 결함처럼 보이고, (2) **결함이 많은 lot 에서 나왔다.**
서로 독립인 두 자가 같은 말을 한다.

**"라벨이 틀렸다" 고 단정하지 않는다.** 확인할 방법이 없다.
말할 수 있는 것은 이것이다 — **남은 none 오검출은 정상의 특징이 뚜렷한 웨이퍼가 아니라,
웨이퍼 안에서도 lot 안에서도 결함의 특징을 갖고 있으면서 라벨이 none 인 쪽이다.**

## 성립 범위

- 이 사이클의 다른 진단과 마찬가지로 **스칼라로 뭉갠 신호**에 대한 이야기다.
  lot 문맥을 모델에 넣는(예: lot 단위 attention) 경로는 배제하지 못한다. **안 해봤다.**
- 조건부 AUROC 는 **현재 앙상블에 상대적**이다.
- lot 당 웨이퍼가 3장 미만인 경우는 뺐다(전체의 2장뿐이라 영향 없음).


## 정정 (같은 날, 02:50) — 위의 "같은 편" 판정은 교란돼 있었다

`FP 대 TN` 비교는 모델의 예측으로 조건을 걸어 선택 효과가 섞인다.
선택을 맞춰 다시 재면 lot 문맥은 `FP 대 TP 0.4632`, `FN 대 TN 0.5884` 로
**약하지만 쓸모 있는 방향**이다. 다만 모델 확신도로 층화하면
`0.5213`, `0.4268` 로 **전부 사라진다 — 모델이 이미 갖고 있는 정보였다.**
그리고 결정 규칙에 넣으면 오라클 가중치가 0 이다.

상세는 [local_density/README.md](../local_density/README.md) 의 정정 절과
`src/diag_signal_headroom.py`. **위 절의 "같은 편이라 못 고친다" 는 표현을 취소한다.
정확한 표현은 "모델 확신도 위에 남는 것이 없다" 다.**
