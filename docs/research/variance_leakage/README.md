# 분산 감소가 왜 성능으로 이어지지 않는가 — 설명이 붙었다

**결론: 두 개의 거의 독립인 양을 하나로 보고 있었다.**
성능(평균)은 `none -> 결함` 누출의 **수준**이 정하고(r = **-0.911**),
seed 분산은 누출의 **퍼짐**이 정한다. 그리고 수준과 퍼짐은 서로 거의 무관하다
(pearson +0.435, spearman **+0.164**). 그래서 퍼짐만 줄이는 기법은 평균을 못 올린다.

재현: `python3 src/diag_variance_vs_leakage.py` (학습 없음, 캐시된 로짓만 읽는다).
원자료 [evidence/variance_vs_leakage.json](evidence/variance_vs_leakage.json).

## 무엇이 설명되지 않았나

`CLASSIFICATION.md` 가 세 번 반복해 기록한 관측이다.

| 기법 | 분산 감소 | 평균 | 판정 |
|---|---|---|---|
| 자기지도 사전학습 | 20배 | -0.037 | 기각 |
| 추가 증강 (scale, dropout, all) | 3~7배 | -0.001 ~ -0.033 | 기각 |
| EMA | 2배 | +0.009 (부호 불일치) | 기각 |
| **translate** | **7배** | **+0.038** | **채택** |

"이 문제에서 분산 감소와 성능 향상이 같이 오지 않는다. 왜인지는 모른다" 라고 적혀 있었다.

## 재본 것

기법군 10개(구성원 2~4개씩)에 대해 군 평균 macro-F1, macro-F1 범위,
`none -> 결함` 누출 평균, 누출 범위를 나란히 쟀다. 전부 이미 캐시된 로짓이라 학습이 0 이다.

## 상관

| 쌍 | pearson r | spearman rho |
|---|---:|---:|
| **F1 평균 대 누출 평균** | **-0.911** | **-0.915** |
| F1 범위 대 누출 범위 | +0.970 | +0.661 |
| **F1 평균 대 F1 범위** | **-0.267** | **+0.091** |
| **누출 평균 대 누출 범위** | +0.435 | **+0.164** |

읽는 법은 이렇다.

1. **성능은 누출 수준이 거의 다 설명한다** (rho -0.915). 기법이 무엇이든 상관없이,
   `none` 110,701장 중 몇 장을 결함이라 부르느냐가 macro-F1 순위를 정한다.
2. **분산은 누출 퍼짐이 설명한다** (rho +0.661).
3. **그런데 누출의 수준과 퍼짐은 거의 무관하다** (rho +0.164). 그래서
   **평균과 분산도 무관하다** (rho +0.091).

즉 세 기법이 한 일은 **누출이 어느 클래스로 얼마나 흘러갈지를 seed 마다 일정하게 만든 것**이고,
**누출 총량을 줄인 것이 아니다.** 총량을 줄인 것은 translate 하나뿐이다(2,962 -> 1,190).

## 이것이 왜 중요한가

분산 감소는 **성능 향상의 전조가 아니다.** 앞으로 "분산이 크게 줄었으니 평균도 오를 것"
이라는 기대로 자원을 쓰면 안 된다 — 상관이 0 이다.

그리고 무엇을 노려야 하는지가 좁혀진다. **누출 총량을 줄이는 것만이 평균을 올린다.**
이것이 E20(국소 밀도 채널)의 근거와 정확히 맞물린다 — 오류의 81.7% 가 none/결함 경계에 있고,
국소 밀도는 학습 없이 그 경계를 AUROC 0.9206 으로 가르는 신호다.

## 남는 것 — 왜 translate 만 총량을 줄이는가

이 문서는 **무엇이 무엇과 연결되는지**를 밝혔을 뿐,
**왜 translate 만 누출 총량을 줄이는지**는 답하지 않는다.
"평행이동 불변성이 none 판정에 특히 중요하다" 는 그럴듯한 이야기를 지어낼 수 있지만
검증하지 않았으므로 쓰지 않는다. 그 부분은 여전히 **설명 없는 관측**이다.

## 성립 범위 (좁게 읽을 것)

- 군이 10개, 군당 구성원이 2~4개다. **군 수준 상관이고 구성원 수준이 아니다.**
- 군들이 서로 독립이 아니다(전부 같은 데이터, 같은 split, 대부분 같은 백본).
- 이 프로젝트가 두 번 실수한 것이 "좁은 범위의 결론을 넓게 옮긴 것" 이다.
  여기서 말할 수 있는 것은 **이 10개 군 안에서** 평균과 분산이 서로 다른 양에 붙어 있다는 것까지다.
