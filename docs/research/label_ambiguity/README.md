# 상한의 정체 — 새는 none 웨이퍼는 라벨이 애매한가 (18차, 2026-08-23)

17차가 상한을 다시 재서 **"none/결함 이진을 완벽히 풀어야 0.8746"** 을 남겼고,
남은 길로 **다양성 축**과 **라벨 애매성** 둘을 지목했다.
18차에 다양성 축은 [ensemble_saturation](../ensemble_saturation/README.md) 에서
**포화**로 확인됐다. 여기서는 나머지 하나를 처음으로 잰다.

**결론부터: 라벨 애매성이 있다는 쪽으로 증거가 기운다. 그러나 증명하지 못했고,
교란 하나를 찾아 절반을 깎았다.**

- 계산: `src/diag_label_neighbors.py` (모델을 쓰지 않는다 — 원본 격자의 해밍 거리만)
- 원자료: `evidence/label_neighbors.json`

## 1. 모델들은 새는 것을 진짜 결함만큼 확신한다

현재 최선 풀(TTA)에서 none 110,701장 중 **900~1,057장이 결함으로 샌다.**
TTA 18개 풀에서 그 1,057장을 구성원 투표로 나눴다.

| 무리 | 장수 | 비율 | 평균 확신도 |
|---|---:|---:|---:|
| **전원(18개) 일치로 결함** | **280** | **26.5%** | **0.857** |
| 3/4 이상 | 440 | 41.6% | 0.680 |
| 과반 | 318 | 30.1% | 0.533 |
| 과반 미만 | 19 | 1.8% | 0.504 |
| 참고: 진짜 결함을 맞힌 것 | 6,365 | | **0.853** |

**전원 일치 280장의 확신도(0.857)가 진짜 결함을 맞힌 것(0.853)과 같다.**
**그 280장은 앙상블을 더 해도 안 바뀐다.**

> **주의: 구성원이 같은 학습 데이터를 봤으므로 만장일치가 독립적 증거가 아니다.**
> 공유된 계통 오차일 수 있다.

## 2. 입력이 같은데 라벨이 갈리는 경우는 거의 없다 — **이 설명은 닫힌다**

64x64 pad 표현에서 **완전히 같은 웨이퍼맵**을 묶었다(모델 무관, 해시).

| | 값 |
|---|---:|
| 완전히 같은 맵 그룹 | 3,252개 (6,510장, 3.76%) |
| **그 중 라벨이 갈리는 그룹** | **14개 (28장, 0.02%)** |
| test 에 있는 것 | **14장 (test 의 0.01%)** |

갈리는 조합은 `Edge-Loc\|none` 7, `Center\|none` 2, `Loc\|none` 2 로
**정확히 문제의 경계**에 있지만 **양이 없다.**

**모델의 입력이 동일한데 라벨이 모순되는 경우는 test 의 0.01% 뿐이다.**
**환원 불가능한 오차의 이 형태는 상한을 설명하지 못한다**(누출 900장 대 14장).

## 3. 새는 웨이퍼는 결함 라벨이 밀집한 자리에 앉아 있다 — **절반은 교란이었다**

새는 none 903장과 **안 새는 none 3,000장**(대조군)에 대해,
학습 43,223장에서 해밍 최근접 이웃을 찾고 그 라벨을 봤다.

| | 최근접이 결함 라벨 | 기저율 대비 |
|---|---:|---:|
| **새는 none** | **85.0%** | 2.61배 |
| 안 새는 none (대조군) | 57.9% | 1.78배 |
| 학습 세트 결함 기저율 | 32.6% | — |

날것으로는 **+27.1%p** 차이다. **그런데 거리 구간별 표가 교란을 드러낸다.**

| 최근접 거리 | 새는 것 | 대조군 |
|---|---:|---:|
| 0~50 | 100.0% (2장) | **0.0%** (91장) |
| 50~100 | 52.6% | 34.4% |
| 100~150 | 81.4% | 63.0% |
| 150~250 | 92.1% | 80.9% |
| 250~ | 93.2% | 85.0% |

**두 무리 모두 거리가 멀수록 결함 이웃이 는다.** 해밍 거리는 "다른 칸 수" 이고
그것은 **불량 다이 개수**에 끌려간다. 그리고 불량이 많으면 결함 라벨이 붙는다.
**즉 위 비교가 "새는 웨이퍼는 불량 다이가 많다" 를 다시 말한 것일 수 있다.**

**불량 다이 개수를 맞춰 다시 쟀다.**

| 불량 다이 수 | 새는 것 n | 결함 이웃 | 대조군 n | 결함 이웃 | 차이 |
|---|---:|---:|---:|---:|---:|
| 19~87 | 215 | 64.7% | 1,880 | 47.8% | +16.8%p |
| 87~110 | 234 | 84.6% | 695 | 69.4% | +15.3%p |
| 110~133 | 228 | 96.5% | 253 | 81.4% | +15.1%p |
| 133~525 | 226 | 93.8% | 165 | 89.7% | **+4.1%p** |
| **층 평균** | | | | | **+12.8%p** |

**날것 +27.1%p 의 절반이 불량 다이 개수 교란이었다. 그래도 +12.8%p 가 남는다.**

## 4. 더 흥미로운 것 — 대조군 자체가 이미 높다

**불량 다이가 133개 이상인 none 웨이퍼는, 새든 안 새든, 최근접 학습 이웃이
결함 라벨일 확률이 90% 안팎이다**(새는 것 93.8%, 대조군 89.7%, 차이 겨우 +4.1%p).

**그 영역에서는 웨이퍼맵만으로 none/결함이 정해지지 않는다는 뜻이다.**
모델이 맞히든 틀리든 이웃은 결함이라고 말한다.

## 5. 무엇을 말하고 무엇을 말하지 않는가

**말하는 것**
- 새는 웨이퍼는 결함 라벨이 밀집한 자리에 있다. 불량 다이 수를 맞춰도 +12.8%p 남는다.
- 불량 다이가 많은 none 웨이퍼는 이웃 기준으로 **거의 구분 불가능한 자리**에 있다.
- 전원 일치로 새는 280장은 진짜 결함만큼 확신되며 앙상블로는 안 바뀐다.

**말하지 않는 것 — 정직하게**
- **"라벨이 틀렸다" 를 증명하지 못한다.** 이웃의 라벨이 정답이 아니다.
- **최근접 이웃이 가깝지 않다.** 중앙값 149칸이 다르고, 다이가 600~1,500칸이므로
  다이의 10~25% 가 다르다. **같은 웨이퍼의 이웃이 아니다.**
- 해밍 거리는 이 데이터에 맞는 거리라는 보장이 없다. 위치, 크기에 민감하다.
- **입력이 동일한 모순 라벨은 0.01% 뿐이라 그 형태로는 설명되지 않는다.**

## 6. 다음 사이클에 넘기는 것

이 조사는 **결론이 아니라 첫 측정**이다. 제대로 하려면 필요한 것 둘.

1. **더 나은 거리.** 위치, 크기에 불변인 기술자로 이웃을 찾아야 한다.
   해밍 거리는 불량 다이 개수에 끌려간다는 것이 위에서 확인됐다.
2. **사람의 재라벨.** 전원 일치 280장을 사람이 다시 보는 것이 결정적이다.
   **이 세션에서는 할 수 없다.** 그것이 진짜 답이고, 나머지는 대리 측정이다.

# 정정 — 위 3절의 결론을 **더 나은 거리로 재서 취소한다** (같은 날 17:55)

위 3절은 **해밍 거리**로 재서 "새는 웨이퍼는 결함 라벨이 밀집한 자리에 앉아 있다"
(불량 개수 통제 후에도 +12.8%p)고 적었다. 그리고 6절에 다음 할 일로
**"위치, 크기에 불변인 기술자로 이웃을 찾아야 한다"** 를 적었다.

**그 기술자를 만들어(`src/a25_wafer_descriptor.py`, 시험 7개) 같은 분석을 다시 돌렸다.
결론이 뒤집힌다.**

## 기술자

위치, 크기, 회전에 불변인 33차원. 셋 다 이번 사이클이 확인한 이 데이터의 대칭에 맞췄다.

1. 정규화 반지름 8구간별 불량 비율 (위치/크기/회전 불변)
2. 구간별 각도 분포의 푸리에 계수 **크기** 1~3차 (회전 불변)
3. 불량 다이의 정규화 퍼짐

**불량 비율은 기술자에 넣지 않고 따로 뒀다** — 앞선 교란이 그것이었기 때문이다.
불변성 셋은 전부 시험으로 박았다(`tests/test_a25_wafer_descriptor.py`).
초안에서 "뭉침" 을 이웃 쌍 **개수**로 셌다가 **크기 불변 시험이 잡아냈고**,
정규화 길이로 바꿨다.

## 결과 — 거의 다 해밍 거리의 인공물이었다

| 최근접 이웃이 결함 라벨일 확률 | **해밍 거리** | **불변 기술자** |
|---|---:|---:|
| 새는 none (903장) | **85.0%** | **19.8%** |
| 안 새는 none (대조군 3,000장) | 57.9% | 11.8% |
| 날것 차이 | +27.1%p | **+8.0%p** |
| **불량 다이 수를 맞춘 층 평균 차이** | **+12.8%p** | **+7.6%p** |
| 학습 결함 기저율 | 32.6% | 32.6% |

**해밍 거리에서는 두 무리 모두 기저율보다 훨씬 높았는데(2.61배, 1.78배),
기술자 거리에서는 둘 다 기저율보다 낮다(0.61배, 0.36배).**

**새는 웨이퍼의 최근접 이웃도 80.2% 가 none 라벨이다.**
최근접 10개 중 결함 비율은 평균 0.182 이고, **과반이 결함인 웨이퍼는 9.9% 뿐**이다.

## 왜 해밍이 틀렸나

해밍 거리는 "값이 다른 칸 수" 이고 그것은 **불량 다이 개수와 웨이퍼 기하**에 지배된다.
불량이 많은 웨이퍼는 모든 것에서 멀고, 그나마 가까운 것이 **불량이 많은 웨이퍼 = 결함 라벨**이다.
3절에서 불량 개수를 층으로 통제해 절반을 걷어냈지만, **개수를 맞춰도 위치와 크기가 남아 있었다.**
거리 구간별 표에서 대조군도 250칸 이상에서 85% 였던 것이 그 징후였고,
**나는 그것을 보고도 "교란이 절반 남았다" 로만 읽었다.**

## 그래서 지금 답은

> **라벨 애매성으로 누출을 설명하기 어렵다.**
> 불변 거리로 보면 **새는 none 웨이퍼는 다른 none 웨이퍼들 사이에 앉아 있다.**

남는 것은 **+7.6%p** 다. 방향은 여전히 "새는 쪽이 결함 이웃이 조금 더 많다" 이지만
**크기가 작고, 절대 수준이 낮다**(19.8% 대 11.8%, 둘 다 기저율 32.6% 아래).

**2절(입력이 같은 모순 라벨 0.01%)과 합치면, 라벨 쪽 설명 두 형태가 모두 약하다.**

## 그러면 1절의 "전원 일치 280장" 은 무엇인가

**모른다.** 구성원 18개가 전원 일치로 평균 확신도 0.857 로 결함이라 부르는데,
그 웨이퍼들의 이웃은 none 이다. 가능성 둘을 적어 두되 **가르지 못했다.**

- **공유된 계통 오차**: 구성원들이 같은 학습 데이터를 봤으므로 같은 실수를 한다.
  만장일치가 독립적 증거가 아니라는 것을 1절에서 이미 밝혔다.
- **기술자가 못 보는 성질**: 33차원이 반지름/각도/퍼짐만 담아
  선 모양(Scratch) 같은 것을 놓칠 수 있다.

**둘을 가르는 실험을 설계하지 못했다. 다음 사이클로 넘긴다.**

## 이 정정이 남기는 방법론

**세 번째로 같은 교훈이다.** 이번 사이클에서 내가 잡은 교란이 셋인데
(대조군 붕괴 모델, 다양성의 품질 교란, 그리고 이 거리 교란)
**셋 다 "자를 바꾸니 결론이 바뀐" 경우다.**
**측정 도구 자체를 대조군으로 검증하지 않으면 그 도구가 결론을 만든다.**

## 그 기술자에 판별력이 있는가 — **자를 대조군으로 검증한다**

위 정정은 **"불변 기술자 공간에서 이웃이 none 이다"** 에 기대고 있다.
**그 기술자가 아무것도 구분 못 한다면 그 관찰은 무의미하다.** 그래서 직접 쟀다.
기술자만으로 kNN 분류(학습 43,223장, test 20,000장 표본).

| | macro-F1 | accuracy | none/결함 이진 정확도 |
|---|---:|---:|---:|
| k=1 | 0.4503 | 0.8430 | 0.8526 |
| k=5 | 0.4558 | 0.8984 | 0.9046 |
| **k=15** | **0.4657** | 0.9072 | 0.9119 |
| 전부 none 으로 찍기 | **약 0.107** | **0.9326** | 0.9326 |
| 학습된 CNN 앙상블 | **0.795** | 0.974 | — |

**판별력은 분명히 있다** — macro-F1 0.466 은 자명한 분류기(0.107)의 4배가 넘는다.
33차원 손 기술자로 9클래스를 이 정도 가른다는 것은 이웃 관계가 의미 있다는 뜻이다.

**그러나 CNN(0.795)에는 한참 못 미친다.** 그리고 accuracy 0.907 은
전부 none 으로 찍기(0.9326)보다 **낮다** — 이 기술자는 결함 쪽으로 과하게 부른다.

### 그래서 정정의 강도를 이렇게 정한다

- **"라벨 애매성이 누출을 설명한다" 는 근거는 약해졌다.** 이것은 확실하다 —
  해밍에서 기저율의 2.61배였던 것이 기술자에서 0.61배로 뒤집혔고, 방향 자체가 바뀌었다.
- **"라벨 애매성이 없다" 를 증명한 것은 아니다.** 기술자가 CNN 이 쓰는 구조의
  일부만 담기 때문이다. **CNN 이 보는 것을 기술자가 못 보는 영역에 애매성이 숨어 있을 수 있다.**
- **전원 일치 280장에 대해서는 여전히 모른다.** 그것을 가르려면
  기술자가 아니라 **사람의 재라벨**이 필요하다. 이 세션에서는 못 한다.

## 전원 일치 280장은 어떻게 생겼나 (설명은 아직 없다)

정정 뒤에도 남은 물음이다. **구성원 18개가 전원 일치로 결함이라 부르는데 이웃은 none 이다.**
그 280장의 성질을 그냥 적어 둔다. **가설이 아니라 관찰이다.**

**어느 클래스로 불리나** — 전체 누출과 사실상 같은 분포다. 특별한 무리가 아니다.

| 불린 클래스 | 전원 일치 280장 | 전체 누출 1,057장 |
|---|---:|---:|
| **Edge-Loc** | **158 (56%)** | 585 (55%) |
| Center | 49 (18%) | 159 (15%) |
| Loc | 40 (14%) | 151 (14%) |
| Scratch | 15 (5%) | 96 (9%) |
| Edge-Ring | 14 (5%) | 47 (4%) |

**불량 다이 비율(중앙값)** — 새는 none 은 **진짜 결함 쪽에 가깝다.**

| 무리 | 불량 비율 |
|---|---:|
| 전원 일치 누출 | 0.1252 |
| 나머지 누출 | 0.1244 |
| **안 새는 none** | **0.0877** |
| 진짜 결함 | 0.1484 |

**전원 일치와 나머지 누출이 구분되지 않는다**(0.1252 대 0.1244).
확신도만 다르고 겉모습은 같다.

**정리하면**: 새는 none 은 **불량 다이가 많고(0.125, 안 새는 none 의 1.4배)
가장자리에 뭉쳐 Edge-Loc 으로 불린다.** 이는 이번 사이클의
[누출 기전](../leakage_mechanism/README.md) 이 낸 그림과 같다 —
