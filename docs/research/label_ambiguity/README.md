# 상한의 정체 — 새는 none 웨이퍼는 라벨이 애매한가 (18차, 2026-08-23)

17차가 상한을 다시 재서 **"none/결함 이진을 완벽히 풀어야 0.8746"** 을 남겼고,
남은 길로 **다양성 축**과 **라벨 애매성** 둘을 지목했다.
18차에 다양성 축은 [ensemble_saturation](../ensemble_saturation/README.md) 에서
**포화**로 확인됐다. 여기서는 나머지 하나를 처음으로 잰다.

**결론부터: 라벨 애매성이 있다는 쪽으로 증거가 기운다. 그러나 증명하지 못했고,
교란 하나를 찾아 절반을 깎았다.**

- 계산: `src/diag_label_neighbors.py` (모델을 쓰지 않는다 — 원본 격자의 해밍 거리만)
- 원자료: `evidence/label_neighbors.json`

## 1. 모델들은 새는 것을 진짜 결함만큼 확신한다

현재 최선 풀(TTA)에서 none 110,701장 중 **900~1,057장이 결함으로 샌다.**
TTA 18개 풀에서 그 1,057장을 구성원 투표로 나눴다.

| 무리 | 장수 | 비율 | 평균 확신도 |
|---|---:|---:|---:|
| **전원(18개) 일치로 결함** | **280** | **26.5%** | **0.857** |
| 3/4 이상 | 440 | 41.6% | 0.680 |
| 과반 | 318 | 30.1% | 0.533 |
| 과반 미만 | 19 | 1.8% | 0.504 |
| 참고: 진짜 결함을 맞힌 것 | 6,365 | | **0.853** |

**전원 일치 280장의 확신도(0.857)가 진짜 결함을 맞힌 것(0.853)과 같다.**
**그 280장은 앙상블을 더 해도 안 바뀐다.**

> **주의: 구성원이 같은 학습 데이터를 봤으므로 만장일치가 독립적 증거가 아니다.**
> 공유된 계통 오차일 수 있다.

## 2. 입력이 같은데 라벨이 갈리는 경우는 거의 없다 — **이 설명은 닫힌다**

64x64 pad 표현에서 **완전히 같은 웨이퍼맵**을 묶었다(모델 무관, 해시).

| | 값 |
|---|---:|
| 완전히 같은 맵 그룹 | 3,252개 (6,510장, 3.76%) |
| **그 중 라벨이 갈리는 그룹** | **14개 (28장, 0.02%)** |
| test 에 있는 것 | **14장 (test 의 0.01%)** |

갈리는 조합은 `Edge-Loc\|none` 7, `Center\|none` 2, `Loc\|none` 2 로
**정확히 문제의 경계**에 있지만 **양이 없다.**

**모델의 입력이 동일한데 라벨이 모순되는 경우는 test 의 0.01% 뿐이다.**
**환원 불가능한 오차의 이 형태는 상한을 설명하지 못한다**(누출 900장 대 14장).

## 3. 새는 웨이퍼는 결함 라벨이 밀집한 자리에 앉아 있다 — **절반은 교란이었다**

새는 none 903장과 **안 새는 none 3,000장**(대조군)에 대해,
학습 43,223장에서 해밍 최근접 이웃을 찾고 그 라벨을 봤다.

| | 최근접이 결함 라벨 | 기저율 대비 |
|---|---:|---:|
| **새는 none** | **85.0%** | 2.61배 |
| 안 새는 none (대조군) | 57.9% | 1.78배 |
| 학습 세트 결함 기저율 | 32.6% | — |

날것으로는 **+27.1%p** 차이다. **그런데 거리 구간별 표가 교란을 드러낸다.**

| 최근접 거리 | 새는 것 | 대조군 |
|---|---:|---:|
| 0~50 | 100.0% (2장) | **0.0%** (91장) |
| 50~100 | 52.6% | 34.4% |
| 100~150 | 81.4% | 63.0% |
| 150~250 | 92.1% | 80.9% |
| 250~ | 93.2% | 85.0% |

**두 무리 모두 거리가 멀수록 결함 이웃이 는다.** 해밍 거리는 "다른 칸 수" 이고
그것은 **불량 다이 개수**에 끌려간다. 그리고 불량이 많으면 결함 라벨이 붙는다.
**즉 위 비교가 "새는 웨이퍼는 불량 다이가 많다" 를 다시 말한 것일 수 있다.**

**불량 다이 개수를 맞춰 다시 쟀다.**

| 불량 다이 수 | 새는 것 n | 결함 이웃 | 대조군 n | 결함 이웃 | 차이 |
|---|---:|---:|---:|---:|---:|
| 19~87 | 215 | 64.7% | 1,880 | 47.8% | +16.8%p |
| 87~110 | 234 | 84.6% | 695 | 69.4% | +15.3%p |
| 110~133 | 228 | 96.5% | 253 | 81.4% | +15.1%p |
| 133~525 | 226 | 93.8% | 165 | 89.7% | **+4.1%p** |
| **층 평균** | | | | | **+12.8%p** |

**날것 +27.1%p 의 절반이 불량 다이 개수 교란이었다. 그래도 +12.8%p 가 남는다.**

## 4. 더 흥미로운 것 — 대조군 자체가 이미 높다

**불량 다이가 133개 이상인 none 웨이퍼는, 새든 안 새든, 최근접 학습 이웃이
결함 라벨일 확률이 90% 안팎이다**(새는 것 93.8%, 대조군 89.7%, 차이 겨우 +4.1%p).

**그 영역에서는 웨이퍼맵만으로 none/결함이 정해지지 않는다는 뜻이다.**
모델이 맞히든 틀리든 이웃은 결함이라고 말한다.

## 5. 무엇을 말하고 무엇을 말하지 않는가

**말하는 것**
- 새는 웨이퍼는 결함 라벨이 밀집한 자리에 있다. 불량 다이 수를 맞춰도 +12.8%p 남는다.
- 불량 다이가 많은 none 웨이퍼는 이웃 기준으로 **거의 구분 불가능한 자리**에 있다.
- 전원 일치로 새는 280장은 진짜 결함만큼 확신되며 앙상블로는 안 바뀐다.

**말하지 않는 것 — 정직하게**
- **"라벨이 틀렸다" 를 증명하지 못한다.** 이웃의 라벨이 정답이 아니다.
- **최근접 이웃이 가깝지 않다.** 중앙값 149칸이 다르고, 다이가 600~1,500칸이므로
  다이의 10~25% 가 다르다. **같은 웨이퍼의 이웃이 아니다.**
- 해밍 거리는 이 데이터에 맞는 거리라는 보장이 없다. 위치, 크기에 민감하다.
- **입력이 동일한 모순 라벨은 0.01% 뿐이라 그 형태로는 설명되지 않는다.**

## 6. 다음 사이클에 넘기는 것

이 조사는 **결론이 아니라 첫 측정**이다. 제대로 하려면 필요한 것 둘.

1. **더 나은 거리.** 위치, 크기에 불변인 기술자로 이웃을 찾아야 한다.
   해밍 거리는 불량 다이 개수에 끌려간다는 것이 위에서 확인됐다.
2. **사람의 재라벨.** 전원 일치 280장을 사람이 다시 보는 것이 결정적이다.
   **이 세션에서는 할 수 없다.** 그것이 진짜 답이고, 나머지는 대리 측정이다.
