# E1~E4b 심층 진단 — 다음 실험 방향을 위한 병목 분석

작성일 2026-08-21. 대상은 `result/cls_baseline/` 의 E1, E3, E4, E4b test 혼동 행렬,
epoch 별 학습 이력, 그리고 캐시와 원본 pickle 로 실측한 split 간 분포다.
계산 스크립트와 원 출력은 [evidence/](evidence/) 에 있다.

혼동 행렬 축은 실측으로 검증했다: 행 합이 support(110,701, 832, ...)와 정확히 일치하고
행 기준 recall 이 json 의 per_class_recall 과 일치하므로 **행=정답, 열=예측**이다.

## 결론 요약 — 가장 중요한 발견 3가지

1. **recall 표가 두 번 속였다. F1 로 보면 그림이 다르다.**
   E1 의 Loc recall 0.571 은 Loc 을 10,273번 남발한 결과다(precision 0.110, none→Loc 오탐 8,319장).
   E3 의 Edge-Ring recall 0.930 도 같은 구조다(precision 0.250, none→Edge-Ring 오탐 2,532장).
   per-class F1 로 다시 보면 **Loc 은 E3 에서 0.184→0.578 로 가장 크게 개선된 클래스**이고,
   E3 의 Edge-Ring F1(0.394)은 오히려 E1(0.572)보다 나쁘다.
   "Loc 은 어떤 기법으로도 개선되지 않았다"는 기존 서술은 recall 만 본 착시다.
2. **오류의 64%는 결함→none 흡수이고, 나머지 결함 간 혼동까지 합치면
   분포 이동이 구조를 결정한다.** E4b 기준 결함 오류 3,370건 중 2,147건(63.7%)이 none 으로
   흡수된다. 실측한 분포 이동은 클래스 비율만이 아니다. train 의 none 은 결함 die 비율
   평균 14.4%인데 test 의 none 은 9.2%(효과크기 0.97)이고, Center 는 test 에서 결함 면적이
   절반(0.255→0.135, 효과크기 1.4), Edge-Ring 은 test 에서 엣지 집중도가 낮은 다른 모양이며
   (0.761→0.641, 효과크기 1.2~1.5), Scratch 는 train 의 median 웨이퍼가 52x52(dieSize 2,393)인데
   test 는 31x31(845)로 크기 자체가 다르다.
3. **인코더 용량은 병목이 아니고, 손실 설계와 사후 보정에 즉시 얻을 여지가 있다.**
   E1 은 train loss 0.009 까지 내려가 학습 분포를 사실상 다 외웠고 val macro-F1 0.886 이다.
   병목은 표현력이 아니라 결정 경계의 위치다. 실제로 4개 실험의 클래스별 최고 F1 만 모아도
   macro 0.693 이 된다(현재 0.6545). 역빈도 가중치의 정밀도 붕괴(Center precision
   0.633→0.447)와 미수렴(15 epoch 에서 loss 하강 중)을 고치는 것이 가장 싼 개선이다.

## 1. 혼동 행렬 정독

전체 행렬과 행 정규화 표는 [evidence/confusion_analysis.txt](evidence/confusion_analysis.txt).
아래는 질문별 답이다.

### Loc — 어디로 가는가

모든 실험에서 Loc 오류의 최대 목적지는 **none**이다. Edge-Loc 혼동은 부차적이며 증강을 켠
실험에서만 커진다.

| 실험 | Loc→none | Loc→Edge-Loc | Loc→Scratch | Loc→Center | recall | precision | F1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| E1 | 730 (37.0%) | 33 (1.7%) | 26 | 45 | 0.571 | 0.110 | 0.184 |
| E3 | 589 (29.9%) | 152 (7.7%) | 69 | 104 | 0.510 | 0.668 | **0.578** |
| E4 | 754 (38.2%) | 62 (3.1%) | 32 | 35 | 0.544 | 0.397 | 0.459 |
| E4b | 631 (32.0%) | 220 (11.2%) | 79 | 59 | 0.486 | 0.402 | 0.440 |

"E1 0.571 → E4b 0.486 으로 떨어졌다"는 recall 기준 서술은 오해를 부른다. E1 의 Loc 예측은
10,273건인데 그중 8,319건이 none 오탐이다(precision 0.110). 후속 실험이 이 남발을 걷어내면서
recall 이 내려간 것이고, **F1 기준으로 Loc 은 E1 0.184 → E3 0.578 로 크게 개선됐다.**
다만 E3 → E4b 에서 0.578 → 0.440 으로 후퇴했다. class weight 가 Loc 표본을 Edge-Loc(+68),
Scratch(+10) 쪽으로 밀고, none 흡수도 +42 늘렸기 때문이다(E3→E4b 델타).

### Scratch — none 으로 흡수되는가

그렇다. 모든 실험에서 Scratch 오류의 최대 목적지는 none 이고(E4b 기준 300건, support 의
43.3%), 2위는 Loc(109건, 15.7%)이다. F1 은 E1 0.203 → E3 0.521 → E4b 0.441 로,
Scratch 도 **E3(증강 단독)이 최고**였고 class weight 결합이 오히려 깎았다.

### Center — E3 0.612 → E4 0.446 의 원인

Center→none 은 거의 변하지 않았다(E1 306, E3 278, E4 303). 무너진 것은 **결함 간 경계**다.
E3 에서 Center→Loc 24건이던 것이 E4 에서 114건, Center→Donut 도 1→24건이 됐다.
역빈도 가중치가 Loc(w=3.59), Donut(w=14.69)을 Center(w=1.73)보다 훨씬 세게 밀어
Center 와 이웃 클래스의 경계가 이웃 쪽으로 이동한 결과다. 대신 Center precision 은
0.525→0.633 으로 올라 F1 손실은 recall 하락보다 작다(0.565→0.523).

### none 흡수(FN) vs 결함 간 혼동 vs none 오탐(FP)의 분해

| 실험 | 결함 오류 합 | →none (FN) | 결함 간 혼동 | none→결함 (FP) | 결함검출 이진 recall | 이진 precision |
|---|---:|---:|---:|---:|---:|---:|
| E1 | 4,170 | 2,828 (67.8%) | 1,342 | 11,027 | 0.642 | 0.315 |
| E3 | 3,050 | 1,610 (52.8%) | 1,440 | 4,162 | **0.796** | 0.602 |
| E4 | 3,487 | 2,435 (69.8%) | 1,052 | 2,835 | 0.692 | 0.658 |
| E4b | 3,370 | 2,147 (63.7%) | 1,223 | 2,631 | 0.728 | **0.686** |

두 가지가 보인다. (1) none 흡수가 항상 결함 오류의 절반 이상이다. (2) 결함을 결함으로
잡는 능력(이진 recall)은 **E3 이 최고**이고 E4b 는 그보다 낮다. class weight 는 FP 를 줄이는
대신 FN 을 늘리는 쪽으로 작동했다.

none 오탐의 목적지는 실험마다 다르다: E1 은 Loc(8,319), E3 은 Edge-Ring(2,532),
E4/E4b 는 Loc(1,110/1,018)과 Edge-Loc(774/871)이 최다다. 각 실험이 "남발하는 클래스"가
그 실험의 recall 착시를 만든다.

## 2. val/test 분포 이동의 실체

원 출력: [evidence/dist_shift.txt](evidence/dist_shift.txt). 원본 크기와 dieSize 는
LSWMD.pkl 을 직접 로딩해 캐시와 행 단위 정렬을 검증한 뒤(라벨 완전 일치) 계산했다.

### 2.1 클래스 비율 — val 은 train 의 복제, test 는 다른 세계

| 클래스 | train % | val % | test % | test/train 비 |
|---|---:|---:|---:|---:|
| none | 67.44 | 68.10 | 93.34 | 1.38 |
| Center | 6.43 | 6.13 | 0.70 | 0.11 |
| Donut | 0.76 | 0.74 | 0.12 | 0.16 |
| Edge-Loc | 4.43 | 4.51 | 2.34 | 0.53 |
| Edge-Ring | 15.69 | 15.94 | 0.95 | **0.06** |
| Loc | 3.10 | 2.53 | 1.66 | 0.54 |
| Random | 1.11 | 1.15 | 0.22 | 0.19 |
| Scratch | 0.94 | 0.83 | 0.58 | 0.62 |
| Near-full | 0.10 | 0.08 | 0.08 | 0.77 |

val 은 train 과 거의 같고(lot 분할이라 당연), test 는 Edge-Ring 이 1/17, Center 가 1/9 로
줄어드는 등 라벨 사전확률 자체가 이동한다(label shift).

### 2.2 웨이퍼 크기 분포 — split 간 실제로 다르다

| | train | val | test |
|---|---|---|---|
| min(H,W) p10/p50/p90 | 25 / 26 / 53 | 25 / 26 / 58 | 26 / **31** / 42 |
| dieSize p50 | 533 | 533 | **845** |
| 64 미만(업샘플) 비율 | 95.5% | 95.8% | **99.9%** |
| 최빈 크기 | 25x27 (28%), 27x25 (17%), 26x26 (12%) | 동일 계열 | 30x34 (10%), 29x26 (10%), 39x37 (9%) |

train 의 최빈 크기(25x27 계열 57%)와 test 의 최빈 크기(30x34 등)가 겹치지 않는다.
64x64 리사이즈의 계단화 정도가 split 마다 다르다는 뜻이다. 특히 클래스별로 보면:

| 클래스 | dieSize p50 (tr → te) | min(H,W) p50 (tr → te) | 업샘플 비율 (tr → te) |
|---|---|---|---|
| Scratch | **2,393 → 845** | **52 → 31** | 68.4% → 99.0% |
| Edge-Ring | **2,126 → 1,075** | **52 → 36** | 83.8% → 100% |
| Donut | 1,334 → 845 | 41 → 31 | 99.1% → 100% |
| Center | 515 → 904 | 25 → 34 | 96.4% → 100% |
| none | 518 → 844 | 25 → 31 | 98.7% → 99.9% |

train 의 Scratch 는 3분의 1이 64 이상 대형 맵(다운샘플, 가는 선 유지)에서 왔는데 test 의
Scratch 는 99%가 소형 맵(업샘플, 두껍고 계단화된 선)이다. 같은 "스크래치"가 픽셀 수준에서
다른 그림이 된다. Edge-Ring 도 같은 방향이다.

### 2.3 패턴의 시각적 통계 — 어느 클래스가 가장 크게 이동했나

캐시 64x64 전체(172,950장)에 대해 결함 die 비율(def_frac), 결함 픽셀의 평균 반경(mean_r),
공간 산포(spread), 엣지 집중도(edge_frac)를 계산했다. train vs test 효과크기
(|평균차| / pooled std) 상위:

| 클래스 | def_frac | mean_r | spread | edge_frac | 해석 |
|---|---:|---:|---:|---:|---|
| Center | **1.43** | 0.91 | 0.86 | 0.94 | test 의 Center 는 결함 면적이 절반(0.255→0.135), 더 바깥쪽 |
| Edge-Ring | 0.84 | **1.24** | **1.48** | **1.26** | test 의 링은 엣지 집중도가 낮고 안쪽(부분 링 형태로 추정) |
| none | 0.99 | 0.37 | 0.36 | 0.61 | test 의 none 이 더 깨끗함(0.144→0.092) |
| Scratch | 0.46 | 0.29 | 0.19 | 0.32 | 픽셀 통계 이동은 중간, 크기 이동(2.2)이 주 |
| Loc | 0.26 | 0.06 | 0.47 | 0.27 | **거의 이동 없음** |
| Donut | 0.16 | 0.06 | 0.33 | 0.41 | 거의 이동 없음 |
| Near-full | 0.01 | 0.27 | 0.28 | 0.42 | 거의 이동 없음 |

세 가지 함의:

- **분포 이동이 가장 큰 클래스는 Center, Edge-Ring, none 이다.** E1 에서 val→test recall 이
  가장 크게 무너진 클래스(Edge-Ring 0.967→0.412, Center 0.966→0.535)와 정확히 일치한다.
- **none 자체가 이동한다.** train 의 none 은 결함 die 14.4%까지 섞인 지저분한 정상인데
  test 의 none 은 9.2%다. train 에서 배운 "none 의 상한"이 test 기준으로 느슨해,
  작은 국소 패턴(Loc, Scratch)이 none 범위 안에 들어가 흡수된다. train 에서 Loc 의
  def_frac 평균(0.136)은 train none(0.144)과 사실상 겹친다. 결함 밀도만으로는 분리가
  불가능하고 공간 구조로만 갈라야 하는 얇은 경계다.
- **Loc, Donut, Near-full 은 시각 통계가 거의 안 변했다.** Loc 의 문제는 Loc 자신의 이동이
  아니라, 이동한 none 과의 경계에 있다. 이는 1절의 "Loc 오류 최대 목적지 = none"과 정합한다.

## 3. 학습 불안정의 원인

원 출력: [evidence/train_dynamics.txt](evidence/train_dynamics.txt).

### 3.1 붕괴는 train loss 에 나타나지 않는다

| | ep3 | ep4 (붕괴) | ep5 |
|---|---|---|---|
| E4 loss | 0.553 | 0.411 (정상 하강) | 0.326 |
| E4 val mF1 / acc | 0.739 / 0.881 | **0.287 / 0.180** | 0.668 / 0.917 |
| E4b loss | 0.498 | 0.388 (정상 하강) | 0.387 |
| E4b val mF1 / acc | 0.572 / 0.785 | **0.161 / 0.143** | 0.693 / 0.908 |

붕괴 시점에도 가중 손실은 정상적으로 내려간다. val accuracy 0.143~0.180 은 val 의 none 비율
68.1%보다 훨씬 낮으므로, 이 시점 모델은 none 대다수를 결함으로 찍고 있었다는 뜻이다.
즉 가중 목적함수 관점에서는 개선이면서 비가중 정확도로는 붕괴인 상태 — 가중치가 만든
목적함수와 평가 지표의 괴리이지, 발산(loss 폭주)이 아니다. 붕괴는 초반에 국한되지도 않는다.
E4b 는 ep11~13 에도 val mF1 0.69/0.67/0.66, ep12 acc 0.527 로 재차 흔들린다.

### 3.2 가중치 실측 — Near-full 은 none 의 648배

train split 라벨로 `class_weights` 를 재계산한 값:

| 클래스 | n_train | weight | w / w_none |
|---|---:|---:|---:|
| none | 29,149 | 0.165 | 1.0 |
| Center | 2,780 | 1.73 | 10.5 |
| Edge-Loc | 1,915 | 2.51 | 15.2 |
| Loc | 1,338 | 3.59 | 21.8 |
| Random | 481 | 9.98 | 60.6 |
| Scratch | 408 | 11.77 | 71.4 |
| Donut | 327 | 14.69 | 89.1 |
| **Near-full** | **45** | **106.72** | **647.8** |

batch 256 기준 Near-full 의 기대 등장 수는 0.27장, **배치의 76.6%에는 아예 없다.**
등장하는 배치에서만 가중치 107의 손실이 몰아치므로 gradient 가 스파이크 형태로 온다.
Scratch(미등장 8.8%), Donut(14.3%), Random(5.7%)도 정도만 다를 뿐 같은 구조다.
증강까지 켜면(E4b) 이 희소 표본이 epoch 마다 다른 모습으로 오므로 진동이 더 커진 것과
부합한다(E4b 의 후반 재붕괴). 이것은 관측과 정합하는 설명이며 gradient 를 직접 측정하지는
않았다(추정).

### 3.3 수렴 여부 — 15 epoch 은 부족하다

- E1: loss 0.0091 로 바닥(학습 분포 암기 수준). 수렴 완료.
- E3: 마지막 3 epoch loss 0.0470→0.0428→0.0406, 여전히 하강. best val 은 ep9.
- E4: 0.117→0.073→0.085, 진동하며 하강. best val 은 ep11.
- E4b: 0.186→0.158→0.148, epoch 당 -0.01 이상 하강 중. best val 은 ep10.

증강, class weight 를 쓴 실험은 모두 **미수렴 상태에서 잘렸고**, best 체크포인트가
후반부가 아닌 중간(ep9~11)에서 나온 것은 수렴을 못 해서가 아니라 val 지표의 진동이
크기 때문이다(인접 epoch 간 ±0.2 요동). 더 긴 학습 + LR 스케줄 + 안정화 없이는
체크포인트 선택이 사실상 추첨이다.

## 4. 증강과 class weight 가 왜 부분적으로만 합쳐지는가

recall 이 아니라 F1 과 precision 으로 보면 겹침의 정체가 드러난다.

| 클래스 F1 | E1 | E3 (aug) | E4 (cw) | E4b | 최고 |
|---|---:|---:|---:|---:|---|
| Edge-Ring | 0.572 | 0.394 | 0.744 | **0.777** | E4b |
| Loc | 0.184 | **0.578** | 0.459 | 0.440 | E3 |
| Scratch | 0.203 | **0.521** | 0.310 | 0.441 | E3 |
| Center | 0.451 | **0.565** | 0.523 | 0.482 | E3 |
| Donut | 0.438 | 0.494 | 0.564 | **0.576** | E4b |
| Random | 0.670 | **0.728** | 0.664 | 0.722 | E3 |
| Near-full | **0.916** | 0.877 | 0.855 | 0.893 | E1 |
| Edge-Loc | 0.438 | 0.584 | **0.600** | 0.582 | E4 |

- 기존 서술("증강은 Edge-Ring 을 살린다")은 recall 착시였다. E3 의 Edge-Ring recall 0.930 은
  precision 0.250(none 오탐 2,532장)과 함께 온 것으로 **F1 은 E1 보다 나쁘다(0.394 < 0.572).**
  Edge-Ring 을 실제로 살린 것은 class weight 쪽이다(E4 F1 0.744, precision 0.844).
- 증강의 진짜 기여는 Loc(0.578), Scratch(0.521), Center(0.565), Random(0.728), 그리고
  결함검출 이진 recall 0.796(4개 중 최고)이다.
- 두 기법은 모두 "결정 경계를 소수 클래스 쪽으로 밀기"라는 같은 축을 조작한다. 합치면
  중간 빈도 클래스(Center, Loc)에서 **과잉 이동**이 일어난다. E3→E4b 델타가 그 증거다:
  Center→Loc +71, Center→Edge-Loc +35, Loc→Edge-Loc +68, Loc→none +42.
  E4b 는 E3 의 Loc, Scratch, Center F1 을 되돌려 준 대가로 Edge-Ring, Donut 을 얻었고,
  순합계가 +0.02 에 그친 이유가 이것이다.
- 4개 실험에서 클래스별 최고 F1 만 골라 모으면 macro 0.693 이다. 새 능력 없이
  **경계 위치(정밀도-재현율 트레이드오프)만 잘 잡아도 0.65→0.69 구간은 열려 있다**는 뜻이다.
  (단일 모델이 이를 동시에 달성할 수 있다는 보장은 없다. 상한 참고치다.)

## 5. 병목 진단

근거와 함께 후보를 소거한다.

| 후보 | 판정 | 근거 |
|---|---|---|
| 인코더 용량 | **병목 아님** | E1 train loss 0.009(암기 수준), val macro-F1 0.886~0.908. 학습 분포 안에서는 이미 충분하다. |
| 입력 해상도(64 리사이즈) | 정보 손실 자체는 부차, **크기 정보 소실은 유효** | test 는 99.9%가 64 미만이라 업샘플이며 리사이즈로 잃는 화소 정보가 없다. 문제는 (i) train 만 대형 맵을 4.5% 포함(Scratch 는 32%)해 같은 클래스의 질감이 split 간 달라지는 것, (ii) 리사이즈가 웨이퍼 절대 크기(dieSize 가 클래스별로 train/test 1.6~2.8배 차이)를 지워 크기 단서를 쓸 수도, 크기 편향을 교정할 수도 없게 만드는 것. |
| 분포 이동 | **주 병목** | val 0.908 vs test 0.655. 라벨 사전확률 이동(Edge-Ring 15.7%→0.95%) + 클래스 조건부 이동(Center def_frac 효과크기 1.4, Edge-Ring 1.2~1.5, none 1.0, Scratch 크기 이동). val→test 붕괴가 가장 큰 클래스와 이동이 가장 큰 클래스가 일치. |
| 손실 함수 / 경계 위치 | **두 번째 병목, 가장 싼 개선처** | 역빈도 무제한 가중치(Near-full 648배)가 학습 진동과 중간 클래스 precision 붕괴(Center 0.633→0.447)를 만든다. 클래스별 최고 F1 조합 = 0.693. |
| 미수렴 | 실재하나 크기 미상 | E3/E4/E4b 모두 15ep 에서 loss 하강 중, best 는 ep9~11 의 진동 꼭대기. |
| 라벨 노이즈 | **미검증 가설** | train none 의 def_frac(0.144)이 Loc(0.136)과 겹치는 것은 정황이며, none/Loc/Edge-Loc 경계의 주석 일관성은 표본을 직접 봐야 안다. 이번 분석에서 확인하지 않았다. |

E4b 혼동 행렬로 개선 여지를 시뮬레이션하면:

| 가정 | macro-F1 |
|---|---:|
| 현재 E4b | 0.6545 |
| 결함→none 흡수(FN)를 전부 정답으로 | 0.7671 |
| 결함 간 혼동을 전부 정답으로 | 0.8158 |
| none 오탐(FP) 전부 제거 | 0.7166 |

세 방향 모두 0.06~0.16 의 여지가 있고 어느 하나만으로는 0.85 에 못 미친다.
FN 흡수와 none FP 는 "none vs 결함" 경계 하나의 양면이므로, 이 경계의 보정이
가장 큰 단일 지렛대다.

## 다음에 시도할 가치가 있는 방향 (우선순위 순)

1. **손실 안정화 + 경계 보정 (가장 싸고 근거 확실).** 가중치 상한(예: w ≤ 10~20) 또는
   sqrt 역빈도, 또는 focal loss 로 E4b 를 재실행. 목표는 E3 의 Loc/Scratch F1 과 E4 의
   Edge-Ring precision 을 한 모델에서 얻는 것. 근거: 4절의 과잉 이동 델타, 3.2절의 648배
   가중치, 오라클 조합 0.693.
2. **label shift 보정.** test 의 라벨 사전확률이 train 과 크게 다르므로(2.1절) logit
   adjustment 나 사후 threshold 보정이 이론적으로 정확히 이 상황용 도구다. test 라벨을
   직접 쓰면 반칙이므로 BBSE 류(모델 예측 분포로 test 사전확률 추정)로 추정치를 쓴다.
   none vs 결함 경계 하나만 보정해도 FN, FP 양쪽에 작용한다(5절 시뮬레이션).
3. **학습 연장 + LR 스케줄 + seed 반복.** 15ep 미수렴(3.3절), val 진동 ±0.2 로 체크포인트
   선택이 불안정. cosine 스케줄로 30ep, 최소 2~3 seed. 현재 실험 간 차이 0.02 는
   단일 seed 라 run-to-run 잡음과 구분되지 않는다(미검증).
4. **Loc, Scratch 오분류 표본 직접 열람.** Loc 은 시각 통계상 이동이 거의 없는데도 none 에
   32% 흡수된다. train none 의 높은 결함 밀도(0.144)와의 경계 문제인지, 라벨 자체의
   모호함인지 표본을 봐야 갈린다. 라벨 노이즈가 크면 모델 쪽 투자 대비 효과가 없다.
5. **pad 모드 캐시 비교(E2 잔여 항목).** 리사이즈가 지우는 절대 크기, 계단화 정도의
   split 간 차이(2.2절)가 Scratch, Edge-Ring 에 실재하므로, 중앙 배치 + 패딩 표현이
   이 두 클래스에서 갈리는지 확인할 가치가 생겼다.
6. E5 사전학습 비교는 계획대로 진행하되, 용량이 병목이 아니라는 진단(5절)상
   큰 이득은 기대하지 않는다.

## 확인하지 못한 것

- 라벨 노이즈의 실재 여부(표본 열람 안 함). 4번 항목으로 남긴다.
- run-to-run 분산(모든 실험이 seed 0 단일 실행). 실험 간 0.02 차이의 유의성은 알 수 없다.
- 붕괴 시점의 gradient 크기 직접 측정(3.2절은 가중치와 등장 확률로부터의 추정).
- 오라클 조합 0.693 이 단일 모델로 달성 가능한지 여부(상한 참고치).
