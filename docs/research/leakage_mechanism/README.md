# 왜 translate 만 none -> 결함 누출을 줄이는가 (18차, 2026-08-23)

17차가 **"설명 없는 관측"** 으로 남긴 물음이다. 여러 기법이 누출의 **퍼짐**(모델 사이 범위)은
줄였는데 **수준**(총량)은 translate 만 줄였다. 설명이 있으면 같은 성질의 기법을 더 찾을 수 있다.

**이 조사가 낸 답은 "설명했다" 가 아니다. 후보 설명 넷을 없애고 물음을 좁힌 것이다.**
그리고 **인계된 숫자 하나를 정정했다.**

- 계산: `src/diag_leakage_mechanism.py`, `src/diag_augment_label_violation.py`
- 시험: `tests/test_diag_leakage_mechanism.py`(12), `tests/test_diag_augment_label_violation.py`(9)
- 원자료: `evidence/leakage_mechanism.json`, `evidence/augment_violation.json`
- 전부 **캐시된 로짓**(`result/posthoc/*_logits.npz`)으로 계산했다. 학습이 없다.

## 정정 1 — 대조군 누출 2,962 는 망가진 모델이 끌어올린 값이다

인계된 값 "2,962 -> 1,190" 의 분자는 resnet18 대조군 **3 seed 평균**인데,
그 중 `e10_pad_s1` 은 **Scratch 가 붕괴한 모델**이다(누출 5,037, 그 중 Scratch 2,007).

| 대조군 | 누출 |
|---|---:|
| e8_pad | 1,861 |
| e10_pad_s2 | 1,989 |
| **e10_pad_s1 (붕괴)** | **5,037** |
| 3 seed 평균 (인계된 값) | 2,962 |
| **건강한 2 seed 평균** | **1,925** |

**translate 의 실제 감소폭은 60% 가 아니라 38% 다**(1,925 -> 1,190).
줄어들긴 하지만 인계문이 말한 크기의 2/3 다.

**그래도 감소 자체는 확실하다.** translate 4 seed 가 875 / 1,168 / 1,191 / 1,527 로
**네 값 모두 건강한 대조군 최저치(1,861)보다 낮다.** 두 분포가 겹치지 않는다.

## 정정 2 — "감소가 모양 클래스에 몰린다" 는 같은 교란이었다

처음 집계에서 위치로 정의된 넷(Center, Donut, Edge-Loc, Edge-Ring) 대비 모양으로 정의된 넷
(Loc, Random, Scratch, Near-full)의 감소율이 **50.4% 대 75.0%** 로 나왔다.
**Scratch 칸을 `e10_pad_s1` 의 2,007 이 혼자 끌고 있었다.**

| 기준 대조군 | 위치 4종 감소율 | 모양 4종 감소율 |
|---|---:|---:|
| 3 seed (붕괴 포함) | 50.4% | **75.0%** |
| **건강한 2 seed** | **37.2%** | **40.9%** |

**비대칭이 사라진다.** 실행 전에 등록한 가설 P("위치 지름길을 끊는다") 는
이 자로는 확인되지도 반증되지도 않는다.

## 실행 전에 적은 경쟁 가설 넷 — 전부 기각됐다

### A. "추가 증강이면 무엇이든 준다" — 기각

| 추가 증강 | n | 누출 (군 평균) | 결함 recall | macro-F1 |
|---|---:|---:|---:|---:|
| 없음 (건강한 대조군) | 2 | **1,925** | 0.7962 | 0.7396 |
| **translate** | 4 | **1,190** | **0.8180** | **0.7645** |
| scale | 2 | 2,500 | 0.8273 | 0.7250 |
| dropout | 2 | 4,014 | 0.8223 | 0.7120 |
| **noise** | 2 | **7,496** | 0.8359 | 0.6752 |
| all (4종 동시) | 2 | 3,672 | 0.8684 | 0.6934 |

**나머지 넷은 누출을 줄이지 않는다. 늘린다.** noise 는 3.9배다.
증강이라는 성질이 아니라 **translate 라는 특정 변환**의 성질이다.

### B. "그냥 결함을 덜 부르는 것" (재현율과 맞바꿈) — 기각

translate 의 결함 recall 은 0.7962 -> **0.8180 으로 오른다.**
**오검출을 줄이면서 검출을 늘린다.** 맞바꿈이 아니다.

### C. "정칙화라 확신도가 낮아졌을 뿐" — 기각. **가장 강한 근거다**

대조군의 none 로짓에 편향을 더해 **누출을 translate 와 같은 1,190 으로 맞췄다**
(`none_bias_for_target_leak`). test 라벨을 보고 맞춘 것이라 **오라클**이다 —
실제로 쓸 수 있는 방법이 아니라 상한이다.

| | 누출 | 결함 recall | macro-F1 |
|---|---:|---:|---:|
| e8_pad, 운영점 맞춤 (편향 +0.94) | 1,190 | 0.7536 | 0.7551 |
| e10_pad_s1, 운영점 맞춤 (+3.10) | 1,190 | 0.7151 | 0.7446 |
| e10_pad_s2, 운영점 맞춤 (+1.27) | 1,190 | 0.7601 | 0.7294 |
| **평균** | 1,190 | **0.7429** | **0.7430** |
| **translate (실제)** | 1,190 | **0.8180** | **0.7645** |

**같은 누출 수준에서 translate 는 recall 을 0.075 더 지키고 macro-F1 이 0.0215 높다.**

재임계화가 translate 의 이득을 얼마나 설명하는지는 **어느 대조군을 쓰느냐에 크게 달린다.**
두 값을 다 적는다.

| 기준 대조군 | 대조군 macro-F1 | 오라클 재임계화 | translate | 재임계화가 설명하는 비율 |
|---|---:|---:|---:|---:|
| 3 seed (붕괴 포함) | 0.7261 | 0.7430 (+0.0169) | 0.7645 (+0.0384) | **44%** |
| **건강한 2 seed** | 0.7396 | 0.7423 (+0.0027) | 0.7645 (+0.0249) | **11%** |

**붕괴한 `e10_pad_s1` 에서만 재임계화가 크게 듣는다**(0.6991 -> 0.7446).
당연하다 — 그 모델의 병은 실제로 운영점이었다(Scratch 를 2,007장 과발화).
**건강한 모델에서는 재임계화가 거의 아무것도 못 한다(+0.0027).**
정직한 요약은 **"재임계화로는 translate 이득의 11~44% 밖에 설명되지 않고,
건강한 모델만 보면 사실상 0 이다"** 다.

> **translate 는 운영점을 옮기는 것이 아니라 판별력 자체를 올린다.**
> 이것이 "사후 보정" 축이 닫혀 있는 것과 일관된다 — 그 축은 운영점만 만진다.

### D. "라벨을 깨뜨리는 증강이 누출을 늘린다" — **내가 세우고 내가 기각했다**

C 를 확인한 뒤 세운 설명이다. `die_noise` 는 정상 다이를 불량으로 뒤집고
`die_dropout` 은 다이를 지우니, none 웨이퍼를 결함처럼 만들어 라벨을 깨뜨릴 것이라고 봤다.
**양방향으로 쟀다** — 증강 없이 학습한 참조 모델 2개로.

| 증강 | none -> 결함 뒤집힘 | 결함 -> none 파괴 | 합 | **실제 누출** |
|---|---:|---:|---:|---:|
| translate | 0.60% | 7.21% | **7.81%** | **1,190** |
| scale | 10.23% | 15.02% | **25.25%** | 2,500 |
| dropout | 0.05% | 6.18% | **6.23%** | 4,014 |
| **noise** | 0.17% | 4.58% | **4.75%** | **7,496** |
| all (4종) | 6.80% | 21.53% | 28.33% | 3,672 |

**관계가 없다. 오히려 반대에 가깝다.** 라벨 파괴가 **가장 적은** noise 가 누출이 **가장 크고**,
파괴가 둘째로 큰 scale 은 누출이 낮은 편이다. **이 설명은 틀렸다.**

(구조 변화도 모델 없이 쟀다 — translate 는 불량 다이를 만들지도 지우지도 않는 유일한 변환이다:
불량 추가 0.0000%, noise 0.8289%, scale 0.4141%. 그런데 그것이 누출을 예측하지 않는다.)

## 남은 것 — 좁혀진 물음과 새 관측 둘

### 관측 1. 누출의 반지름 의존은 **국소 3종에만** 있다

불량 다이 무게중심이 다이 영역 중심에서 얼마나 떨어져 있는지로 none 웨이퍼를 5분위로 나눴다
(다이 영역의 RMS 반지름으로 정규화해 **웨이퍼 크기에 불변**이다).

| 군 | Q1(중심) | Q2 | Q3 | Q4 | Q5(가장자리) | Q5/Q1 |
|---|---:|---:|---:|---:|---:|---:|
| 대조군, **국소 3종**(Edge-Loc/Loc/Scratch)으로 누출 | 1.73% | 1.72% | 2.05% | 2.39% | **4.06%** | **2.35** |
| 대조군, 전역 3종(Center/Donut/Edge-Ring)으로 누출 | 0.27% | 0.30% | 0.27% | 0.25% | 0.26% | 0.95 |
| **translate, 국소 3종** | 0.65% | 0.70% | 0.84% | 0.77% | **1.09%** | **1.67** |
| translate, 전역 3종 | 0.30% | 0.28% | 0.27% | 0.20% | 0.23% | 0.78 |

**전역 3종에는 반지름 의존이 아예 없다**(0.95, 0.78). 있는 것은 국소 3종뿐이고,
translate 는 **수준을 절반 이하로 내리면서 기울기도 2.35 -> 1.67 로 눕힌다.**
즉 "가장자리에 우연히 뭉친 불량 다이를 Edge-Loc 이라 부르는" 실패가 줄어든다.

클래스별로도 같은 그림이다(건강한 대조군 대비 translate):
**Edge-Loc -585, Loc -100, Scratch -91** 이 감소의 전부이고,
**Center +35, Donut +7, Edge-Ring +6 은 오히려 는다.**

### 관측 2. scale 은 전역 패턴을 부순다

`random_scale` 은 다이 격자를 nearest 로 다시 뜬다. 그 결과 none -> Center 누출이
대조군 139 에서 **804** 로, Edge-Ring 이 88 에서 **372** 로 뛴다.
가설 D 의 자로도 scale 의 뒤집힘 비율만 10.23% 로 유독 높다(나머지는 전부 1% 미만).
**scale 은 이 데이터셋의 대칭이 아니다** — 링 반지름과 원판 크기가 곧 라벨이기 때문이다.

### 아직 설명 없는 것 (정직하게 남긴다)

> **왜 translate 만 판별력 자체를 올리는가.**

C 가 보인 것은 "운영점이 아니다" 이고, D 가 보인 것은 "라벨 파괴량이 아니다" 다.
남은 그럴듯한 이야기는 **"캔버스 안 위치는 이 표현에서 순수한 잡음 변수이고,
translate 는 그것을 제거하는 유일한 참된 대칭"** 인데 —
`a18_augment.random_translate` 의 주석이 이미 그렇게 적고 있다 —
**나는 그것을 재지 않았다.** 대칭이라는 성질과 판별력 향상 사이를 잇는 측정이 없다.
가설 D 가 그 시도였고 실패했다. **모른다고 쓴다.**

**다음에 이걸 재려면** 필요한 것은 "참된 대칭" 을 양으로 정의하는 자다.
후보 하나: 학습된 모델의 예측이 변환에 대해 얼마나 불변한지를
**변환 전후의 KL** 로 재고, 그 불변성이 누출과 어떻게 붙는지 본다.
지금 자(argmax 뒤집힘)는 너무 거칠어서 noise 처럼 확신도만 흔드는 변환을 못 잡는다.

## 이 조사가 다음 실험에 준 것

E22(백본 x translate)에 **독립적인 검증**이 하나 생겼다. 누출 수준이 축마다 뚜렷이 다르므로
(translate 대역 1,190, 백본 대역 2,844), E22 구성원의 누출이 어느 대역에 앉는지를 보면
**translate 가 백본에 전이했는지를 macro-F1 과 다른 자로 확인할 수 있다.**
반증선(1,600)은 E22 결과를 보기 전에 candidate 문서에 박았다.

# 뒤에 이어서 — 물음에 부분적인 답이 나왔다 (18차, 같은 날 16:15)

위에서 "왜 translate 만 판별력을 올리는가는 모른다" 고 적고, 필요한 자를
**"모델의 예측이 변환에 얼마나 불변한지"** 라고 적어 뒀다. 그 자를 만들어 쟀다
(`src/diag_shift_sensitivity.py`, 시험 6개, 원자료 `evidence/shift_sensitivity.json`).

## 자

같은 none 웨이퍼를 ±4칸 옮겨 넣고 **예측 분포가 얼마나 움직이는지**를 총변동거리로 잰다.
argmax 뒤집힘보다 섬세하다 — 확신도만 흔드는 변환도 잡힌다(가설 D 를 재던 자가
그것을 못 잡아 실패했다).

**대조군 변환을 같이 잰다.** `die_noise` 는 위치와 무관한 교란이므로,
어떤 모델이 그냥 전반적으로 예민한 것인지 **위치에만** 예민한 것인지를 가른다.

## 순환을 피하는 설계

translate 로 학습한 모델이 이동에 둔감한 것은 **동어반복**이다.
그래서 **translate 를 쓰지 않은 모델 28개 안에서** 관계를 본다.
그 28개에는 E18 백본 7종이 들어 있고 누출이 1,246~3,939 로 3배 넘게 벌어진다.

## 결과 — 그리고 교란을 먼저 찾은 것이 결론을 뒤집었다

| 군 (n) | 이동 민감도 | 잡음 민감도 | 이동/잡음 | 누출 |
|---|---:|---:|---:|---:|
| noise (2) | 0.0971 | 0.0384 | 2.53 | 7,496 |
| dropout (2) | 0.0525 | 0.0224 | 2.34 | 4,014 |
| 무증강 resnet18 (13) | 0.0480 | 0.0194 | 2.47 | 3,555 |
| 백본, 무증강 (7) | 0.0365 | 0.0146 | 2.51 | 2,844 |
| scale (2) | 0.0245 | 0.0161 | 1.52 | 2,500 |
| all (2) | 0.0125 | 0.0243 | 0.51 | 3,672 |
| **translate 계열 (7)** | **0.0054** | **0.0052** | **1.03** | **1,127** |

**날것의 상관만 보면 잘못 읽는다.** 누출과의 상관이 잡음 민감도(+0.947)가
이동 민감도(+0.895)보다 높아서, 처음에는 **"위치가 아니라 그냥 전반적인 불안정성"** 으로 읽었다.
그런데 **불안정성은 품질과 얽혀 있다** — 누출과 macro-F1 의 상관이 **-0.930** 이다.

**macro-F1 을 통제하고 다시 쟀다(부분상관).**

| translate 안 쓴 28개 | 날것 상관 | **macro-F1 통제 후** |
|---|---:|---:|
| 누출 x **이동** 민감도 | +0.895 | **+0.870** |
| 누출 x 잡음 민감도 | +0.947 | **+0.583** |
| 누출 x (이동/잡음 비) | +0.122 | **+0.543** |

**순서가 뒤집힌다.** 품질을 빼고 나면 남는 것은 **위치 민감도**다.
잡음 민감도의 높은 날것 상관은 거의 전부 "나쁜 모델이 불안정하다" 였다.
이동/잡음 비도 날것으로는 +0.122(관계 없음)인데 통제하면 **+0.543** 이 된다.

## 그래서 답은

> **none -> 결함 누출은 모델이 절대 위치에 얼마나 예민한지가 몰고 간다.
> translate 는 그 예민함을 9배 줄이는(0.0480 -> 0.0054) 유일한 기법이고,
> 이동/잡음 비를 1.0 으로 만드는 것도 그것뿐이다(나머지는 전부 2.3~2.5).**

이것이 위의 관측 1(누출의 반지름 의존이 국소 3종에만 있다)과 정확히 같은 이야기다.
가장자리에 우연히 뭉친 불량 다이를 Edge-Loc 이라 부르는 실패는 **절대 위치를 쓰는 실패**이고,
위치를 못 쓰게 하면 사라진다.

## 이 답의 한계를 분명히 한다

1. **모델 사이의 상관이지 개입이 아니다.** 위치 민감도를 직접 조작하고 누출을 본 것이 아니다.
2. **"translate -> 낮은 이동 민감도" 는 동어반복이다.** 순환이 아닌 부분은
   **"이동 민감도 -> 누출"** 이고, 그것을 translate 를 안 쓴 28개 안에서 쟀다.
3. **제3의 요인이 남아 있을 수 있다** — 어떤 모델은 그냥 전반적으로 매끄러울 수 있고,
   부분상관은 그것을 macro-F1 으로만 통제한다.
4. `all`(4종 동시)이 이동/잡음 비 0.51 로 가장 낮은데 누출은 3,672 로 높다.
   **비율만으로는 안 된다 — 수준도 낮아야 한다.** 이 반례를 표에 남긴다.

## E23 이 이것의 개입 시험이 된다 (실행 전에 적는다)

E23(자유 각도 회전)은 **다른 잡음 변수**를 지운다. 그래서 이 기전을 가른다.

- **기전이 "이동 특유" 라면**: 회전은 이동 민감도를 크게 못 줄이고 **누출도 못 줄인다.**
- **기전이 "기하 잡음 변수 일반" 이라면**: 회전도 누출을 translate 대역(1,600 미만)으로 내린다.

**둘 중 어느 쪽이든 이 기전 이야기를 검증하거나 반증한다.** E23 결과가 나오면
회전 민감도까지 같은 자로 재서 여기 붙인다.

# 정정 — **"translate 가 반지름 기울기를 눕힌다" 는 틀렸다** (같은 날 18:10)

관측 1 절에 이렇게 적었다.

> translate 는 국소 3종의 **수준을 절반 이하로 내리면서 기울기도 2.35 -> 1.67 로 눕힌다.**

**뒤쪽 절반이 틀렸다.** 그 2.35 는 **붕괴한 `e10_pad_s1` 이 들어간 3 seed 대조군**의 값이다.
이 문서의 정정 1, 2 에서 이미 같은 모델을 두 번 걷어냈는데 **이 표에서는 못 걷었다.**

| 국소 3종으로의 오검출률, 반지름 5분위 | Q1 | Q2 | Q3 | Q4 | Q5 | **Q5/Q1** |
|---|---:|---:|---:|---:|---:|---:|
| 3 seed 대조군 (붕괴 포함 — **내가 쓴 것**) | 1.73% | 1.72% | 2.05% | 2.39% | 4.06% | **2.35** |
| **건강한 2 seed 대조군** | 1.22% | 1.24% | 1.44% | 1.56% | 2.10% | **1.71** |
| 붕괴한 `e10_pad_s1` 혼자 | 2.73% | 2.69% | 3.27% | 4.06% | 7.98% | **2.92** |
| translate 4 seed | 0.65% | 0.70% | 0.84% | 0.77% | 1.09% | **1.67** |

**건강한 대조군 1.71 과 translate 1.67 은 구분되지 않는다.**

## 고쳐 쓴 결론

> **translate 는 모든 반지름 구간에서 누출을 약 47% 씩 균일하게 낮춘다.
> 반지름 의존 자체는 건드리지 않는다.**

Q1 1.22% -> 0.65% (-47%), Q5 2.10% -> 1.09% (-48%). **기울기가 아니라 수준이다.**

## 그리고 미검출 쪽도 마찬가지다

| 군 | 미검출 Q1 -> Q5 | Q5/Q1 | 오검출 Q1 -> Q5 | Q5/Q1 |
|---|---|---:|---|---:|
| 무증강 대조군 (건강) | 30.2% -> 10.3% | **0.34** | 1.22% -> 2.10% | **1.71** |
| translate | 26.9% -> 10.5% | **0.39** | 0.65% -> 1.09% | **1.67** |
| E22 백본 x translate | 30.4% -> 11.4% | 0.37 | 0.76% -> 1.06% | 1.39 |
| noise | 26.5% -> 6.3% | 0.24 | 4.49% -> 10.15% | 2.26 |

**어느 조리법도 기울기를 못 바꾼다.** translate 는 양쪽의 **수준**을 낮추고,
noise 는 양쪽의 기울기를 오히려 세운다.

## 그래서 handoff 가 더 선명해진다

**반지름 사전지식은 모든 모델에 있고, 이 프로젝트가 시도한 어떤 것도 그것을 바꾸지 못했다.**
translate 가 통한 이유는 **그 사전지식을 약화시켜서가 아니라** 다른 무엇 때문이다
(위치 민감도를 9배 줄이는 것이 그 후보이지만, 그것이 반지름 기울기로는 안 나타난다).

**"반지름 사전지식을 끊으면 두 오류가 같이 줄어드는가" 는 아직 아무도 시험하지 않았다.**
그것이 이 사이클이 남기는 가장 구체적인 물음이다.

## `e10_pad_s1` 이 이 사이클에서 오염시킨 결론 셋

1. 대조군 누출 총량 (2,962 -> 실제 1,925)
2. 누출 감소의 클래스 비대칭 (75% 대 50% -> 실제 37% 대 41%)
3. **반지름 기울기 (2.35 -> 실제 1.71)**

**모델 하나가 세 번 결론을 바꿨다. 붕괴한 구성원은 대조군에서 빼야 한다** —
그런데 그것을 빼는 근거가 test 성능이면 사후 선택이다.
**val 로도 그 모델이 최하위였는지는 확인하지 않았다.** 다음 사이클의 숙제로 남긴다.

---

# 이 사이클의 정정 셋에 붙는 **공통 단서** — "건강한 대조군" 은 test 를 보고 고른 것이다

이 문서(그리고 `binary_boundary`, `CLASSIFICATION` 의 정정 2, 3)에서
붕괴한 `e10_pad_s1` 을 빼고 **"건강한 2 seed 대조군"** 을 썼다.
**그것을 빼는 근거가 무엇이었는지를 확인했다. test 성능이었다.**

## val 로는 그 모델을 못 걸러낸다 — 오히려 최고다

| 모델 | **val macro-F1** | test macro-F1 | val Scratch F1 |
|---|---:|---:|---:|
| e8_pad | 0.9361 | **0.7485** | 0.8406 |
| **e10_pad_s1 (붕괴)** | **0.9401 (최고)** | **0.6991 (최저)** | 0.8529 |
| e10_pad_s2 | 0.9357 | 0.7308 | 0.9503 |

**무증강 3개 중 val 최하위는 `e10_pad_s2` 이고 test 최하위는 `e10_pad_s1` 이다. 반대다.**
그리고 붕괴한 모델이 **val 에서는 셋 중 1위**다. val Scratch F1 도 0.8529 로
정상 범위다 — test 에서 Scratch 를 2,007장 과발화하는데 val 에서는 안 보인다.

일곱 모델에서 val 과 test macro-F1 의 상관은 **0.379** 다. 약하다.
(이것은 13차에 "val 로 고르기를 포기" 한 것과 같은 사실이다.)

## 그래서 정직한 서술은 이렇다

> **`e10_pad_s1` 을 빼는 것은 test 라벨을 본 사후 선택이다.**
> **빼지 않은 3 seed 대조군이 "고르지 않은" 대조군이고, 뺀 2 seed 는 고른 것이다.**

**그렇다고 정정이 무의미해지는 것은 아니다.** 정정이 실제로 보인 것은

- **결론이 모델 하나에 크게 좌우된다** (누출 2,962 대 1,925, 기울기 2.35 대 1.71,
  클래스 비대칭 75%/50% 대 37%/41%).
- **그 모델은 평균을 끌고 갈 만큼 극단이다** (누출 5,097 대 1,861/1,989,
  이동 민감도 0.0577 대 0.0250).

**즉 "3 seed 평균" 이라는 요약 통계 자체가 이 경우 부적절하다.**
n=3 에서 하나가 극단이면 평균은 그 하나를 보고한다.

## 앞으로 어떻게 보고해야 하나

1. **군 평균만 쓰지 말고 개별 값을 같이 낸다.** 이 사이클의 표들이 대부분 그렇게 했지만
   반지름 기울기 표는 안 그랬고, 그래서 세 번째 오염이 거기서 났다.
2. **대조군을 바꿀 때는 "왜 바꿨는지" 와 "그 근거가 test 인지" 를 명시한다.**
   이 문서가 그 명시다.
3. **양쪽을 다 보고한다.** 이 사이클의 수치는 아래처럼 읽어야 한다.

| | 3 seed (안 고름) | 2 seed (test 보고 고름) |
|---|---:|---:|
| 대조군 누출 | 2,962 | 1,925 |
| 국소 3종 반지름 기울기 | 2.35 | 1.71 |
| 이동 민감도 | 0.0480* | 0.0250 |
| macro-F1 | 0.7261 | 0.7396 |

(*13개 무증강 resnet18 군 평균. E24 의 사전 등록선 0.030 이 이 값에서 유도됐다 —
**즉 사전 등록선 자체가 오염된 기준선에서 나왔다.** 선은 옮기지 않되 이 사실을 밝힌다.)

**`e10_pad_s1` 이 이 사이클에서 오염시킨 것이 넷이다** — 위 셋에 더해
**E24 의 사전 등록 임계값**까지.
